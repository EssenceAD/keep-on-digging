# 용사님, 채굴하실게요~ (Keep On Digging)

모험의 유산(체크인) 세계관 스핀오프 아이들러. 기획: `EssenceAD/legacy-of-adventure` → `docs/mining/MINING_SPEC_1_1024.md` · `MINING_VISUAL_1024.md`.

**지금 단계: HD-2D 비주얼 프로토타입 (명세 §10-2).** 형철 폰에서 "이 느낌 맞다" 확인 후 본 개발.

- 웹: https://essencead.github.io/keep-on-digging/  (`?low=1` 저사양 · `?ambient=0.3` 앰비언트 조절)
- 기준 그림: pxl 공식 예제 `no_magic_night` → 화면 오른쪽 아래 [pxl 기준컷]으로 pxl이 구운 장면과 비교

## 구조
- `art/mine.px.js` — 아트 전부 (pxl DSL, 한 팔레트). `npm run art` 로 빌드 → `public/art/`
  - pxl: `crsolver/claude-pxl` (MIT) 를 `~/.claude/skills/pxl-pixel-art` 에 클론 (다른 경로면 `PXL=…/bin/pxl.js`)
- `src/main.js` — 장면 · 입력 · 주스 · HUD / `src/gl.js` — 조명 합성·후처리 셰이더 / `src/sound.js` — 합성 효과음
- 렌더: 알베도 RT + 노멀 RT → 조명 셰이더 → 발광·헤일로 → 후처리 → 정수 배율 확대 (장면 높이 224px)
- 지상 띠는 pxl이 조명까지 구운 PNG (런타임 비용 0)

## 명령
```bash
npm install
npm run dev      # 로컬
npm run art      # 아트 다시 굽기
npm run deploy   # gh-pages 배포
```
