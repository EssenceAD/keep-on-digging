## 한 라운드 (명세2 §2~§9)
| 단계 | 하는 것 |
|---|---|
| 경매 | 구획 카드 3장(이름·크기 S/M/L·힌트 2·시작가). [입찰] → +10/25/50% 또는 포기. 길드 3곳(공격적·신중·랜덤)이 평가액까지 따라옴 → 2라운드에 한 번 더 올릴 기회 → 낙찰. 놓치면 공짜 자투리 구획 |
| 탐사 15초 | 두더지가 지상을 걷다 아래 3칸 안 광맥 위에서 킁킁(클수록 오래). [투시 랜턴] 하루 2회: 톡한 곳 3×3이 2초 보임. 격자는 전부 가려진 흙 |
| 시추 | 0줄·뚫린 칸에서 손가락을 끌면 갱도 경로(주황 선 + 예상 초, 광부 발밑은 빨간 깜빡임). 못 뚫는 칸(단단한 바위·고대석)에서 빨간 X로 끊김. 붉은 수염이 차례로 파고, 세로로 판 칸엔 사다리. 광맥에 닿으면 덩어리 통째로(금색 테두리), 12칸↑ 대박 연출 |
| 광부 3 | 붉은 수염 = 선두 채굴 · 뚱보·금발 = 광석을 광차로 운반(머리 위 광석). 체력 ♥3, 0이면 지상에서 10초 쉼. [광부] 탭에서 상태 |
| 중력 | 발밑이 비면 멈칫 → 가속 낙하 → 착지(먼지·엉덩방아·"으악!"). 2칸↑ 기절 ★, 4칸↑ 기절 + 체력 −1. 막다른 구덩이면 사다리를 놓고 나옴. 광차가 떨어지면 적재 절반이 흩어지고 광부가 주워 담음 |
| 광차 | 뚫린 길에 레일 자동 부설 · 세로 갱은 도르래. 붉은 수염 근처에 서 있다가 8개 차거나 캘 게 없으면 지상 창고로. 창고 60 꽉 차면 지상에서 멈추고 광부들 팔짱 |
| 사건 | 붕괴(뚫린 칸 15↑, 20~60초) · 지하수(아래로 차오름, 걸음 ½, 광차 못 지남, [펌프 30]) · 가스(30초 정지·초록 가장자리, 랜턴을 2칸 안으로 끌면 폭발 3×3 + 체력 −1) · 동굴 슬라임(10%, 광차 길막 10초) |
| 판매 | 매입자 토글(브로크: 구리·은 +15% / 떠돌이 상인: 금·보석·발광 +15%, 나머지 −10%). 시세 10초마다 랜덤 워크(0.5~2.0, 평균 회귀). 하루 1~2번 모모 편지 30초 뒤 급등 ×1.8 40초(행 깜빡). [팔기] [절반] [전부 팔기] |

HUD [특성n] · 결과 카드 [특성 찍기]. 탐사(힌트 3 · 투시+1 · 진동계+1 · 광종 색 · 범위±1 · 단서 70% · 가치 범위 · 광맥 실루엣) / 채굴(+10% · 흙 0.3초 · 광차+1 · 기절½ · +20% · 적재+5 · 인접 광맥 · 광부 조+1) / 장사(+5% · 미리보기 · 예고 60초 · +10% · 페널티−5% · 급등×2.0 · 대박 10칸 · 고정 2회). 찍으면 화면 가운데 숫자가 튀고 광부들이 "오!". 예전 5단 특성은 한 번 되돌려 포인트로 돌려줌.
5. **이름·세계관** — 광부 브릭(성급: 채굴 +10% · 사고 ×1.5) · 툼바(느긋: 운반 −10% · 가스 면역) · 엘린(꼼꼼: 유물 +20%), 할아범 돌망치 그룬, 두더지 꼬물. 숙소를 올리면 도르·핀·마르타·우글이 왼쪽 다리에서 걸어 들어오며 이름·성격 카드. 성격 숫자는 `balance.js` `traits`·`recruits`.
6. **튜토리얼 18단계 + 설명서** — 꼬물 지켜보기 → 탐사 끝 → 입구 톡 → 자동 파기 → [◀]로 구리 → 광차 → 판매 → 진동계(깊이 6~7) → 말뚝 자리에 둘째 입구(금) → 상인에게 금 → [장비] 곡괭이(모자라면 그룬이 보탬) → 철수 → 결과 [특성 찍기] → 1점 → 닫기 → 첫 경매. 설명서에 탐사 도구 · 장비와 특성 · 광부들 쪽 추가, 회사 건물 쪽은 뺌.
7. **경매 재설계 + 정보량 규칙** — 고르기 = 카드 3장만(구획 단면 그림 · 이름 · 크기 · 힌트 · 시작가 · [입찰]), 시세·광부 시트 숨김. 입찰 = 위 구획 그림(격자로 코드가 그린 96×64, 힌트 있는 것만 희미하게: 바위층·물·발광 점·상자) · 예상 가치·이익 막대 · 왼쪽 "나"(브릭 초상 + 노란 「나」 뱃지 + 금화) 크게 ↔ 오른쪽 상대 3 작게 한 줄 · 말풍선 1줄 하나만 · 현재가 · [올리기] [포기] · 낙찰 도장 "낙찰! N금" 뒤 1.3초에 탐사. PC도 좌우 패널 없이 폰 비율 세로 기둥(가운데). 토스트는 1개·3초·같은 글은 "×3"으로 합침. 아래 시트는 새 세이브에서 접힘 기본.
