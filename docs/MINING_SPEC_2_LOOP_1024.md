# 「용사님, 채굴하실게요~」 — 2단계 명세: 핵심 루프 (v1 · 2026-10-24 03:05)

> 비주얼 프로토타입 v0.4 **통과**(형철 폰 확인). 이제 아트는 그대로 두고 **게임**을 만든다.
> 범위 = 명세1 §10-3 "경매 → 탐사 → 시추 → 광차 → 창고 → 판매 → 결과" 한 라운드가 끊김 없이 도는 것. 방치·회사·특성은 다음 명세.
> 원칙: 명세1 §0. 숫자는 전부 `src/balance.js` 한 파일에 모아 형철이 바꿀 수 있게.

## 0. 이번 단계 완료 조건
1. 앱을 열면 **경매 → 구획 선택 → 탐사 → 시추(갱도 그리기) → 광차 운반 → 판매 → 라운드 결과 → 다음 경매**가 돈다. 임시 데이터·버튼 없음.
2. 라운드 하나 5~8분. 첫 라운드는 튜토리얼 말풍선(모모) 6개로 안내.
3. 중력 규칙(§1) · 사건 3종(붕괴·가스·지하수) · 큰 광맥 연출 · 시세 랜덤 워크 + 급등 이벤트가 라운드 안에서 실제로 일어난다.
4. 저장: 라운드 중간 상태 포함 **로컬 자동 저장**(localStorage, 5초마다 + 종료 시). 클라우드는 다음 명세.
5. 세로 폰 기준, 패드·PC 반응형 유지. 45fps.

## 1. 중력 (v0.4 "공중부양" 버그 → 규칙)
- 광부·광차·두더지는 **발밑 칸이 비면 떨어진다**: 0.15초 멈칫 → 가속 낙하(칸당 0.08초, 최대 6칸/초) → 착지: 먼지 이펙트(fx `dust`) + 0.5초 엉덩방아 프레임 + 말풍선 "으악!".
- 낙하 높이 ≥ 2칸: **기절 1.5초**(곡괭이 멈춤, 머리 위 ★ 뱅글). ≥ 4칸: 기절 3초 + 광부 체력 −1(§6).
- 광차가 레일 없는 칸으로 떨어지면 적재 광석 **절반이 바닥에 흩어짐**(칸에 광석 조각 아이콘 1~4개). 광부가 지나가면 자동으로 주워 담음(조각당 0.5초).
- 갱도를 그릴 때 **광부가 서 있는 칸 바로 아래**를 지나는 경로는 미리보기 선이 빨갛게 깜빡임(경고만, 금지 아님). 일부러 떨어뜨려 빨리 내려가는 건 허용 — 꼼수는 재미다.
- 지금 뚫린 칸에 이미 서 있던 캐릭터는 즉시 낙하.

## 2. 라운드 상태 기계
```
AUCTION → SURVEY → DIG ⇄ SELL(겹침 가능) → RESULT → AUCTION
```
- `DIG` 중 언제든 하단 시트 [판매] 탭으로 판다(SELL은 모달이 아니라 탭). `RESULT`는 [철수] 또는 광맥 전부 고갈 시.
- 게임 시계: 현실 24분 = 게임 하루(체크인 `clock` 재사용). 하루에 경매 1회. 라운드가 하루를 넘겨도 됨(다음 경매는 라운드 끝나고 바로).

## 3. 경매 (AUCTION)
- 구획 카드 3장(세로: 세로로 3장 스택, 가로: 가로 3장). 카드 = 이름(「뒷산 북쪽 비탈」식 생성) · 크기 S/M/L(격자 12×10 / 12×14 / 12×16) · 힌트 아이콘 2개 · 시작가.
- 힌트 → 생성 규칙(명세1 §2-1 그대로): 🪨 바위층 40% / 💧 지하수 1~2 / 🏺 유물 상자 1 / ✨ 발광 광석 확률 ×3. 힌트는 참이지만 전부는 아님.
- 시작가: S 120 · M 220 · L 360 (금화). 플레이어 금화 시작 400.
- **입찰**: 버튼 3개 [+10%] [+25%] [+50%] + [포기]. AI 길드 3곳(「심연낚시 동호회」 공격적 · 「탑오르는중」 신중 · 「방패장인 조합」 랜덤) 성향:
  - 공격적: 자기 평가액 ×1.3까지 따라옴, 60% 확률로 +25%
  - 신중: 평가액 ×1.0까지만, 항상 +10%
  - 랜덤: 평가액 ×(0.8~1.4), 호가 무작위
  - 평가액 = 시작가 × (1 + 힌트 수 × 0.15) × 길드별 ±10%
- 2라운드: 1라운드에 전원 호가 → 최고가에 플레이어가 한 번 더 올릴 기회 → 낙찰. 낙찰 못 하면 **공짜 구획**(힌트 없음, S, 광맥 적음)으로 들어간다 — 라운드가 끊기지 않게.
- 낙찰 시 금화 차감, 카드가 뒤집히며 격자 생성(시드 저장).

## 4. 탐사 (SURVEY) — 15초 제한, 건너뛰기 가능
- 지상 띠에서 **두더지**가 좌우로 걷다가 아래 3칸 안에 광맥이 있으면 그 x에서 킁킁(이모트 + 소리). 광맥이 클수록 오래 킁킁. 깊이는 모름.
- [투시 랜턴] 버튼(이번 단계는 하루 2회 고정): 탭한 지점 아래 3×3이 2초간 반투명으로 보임.
- 탐사 끝나면 광부 3명 + 광차가 지상에 서 있고, 격자는 전부 가려진 흙.

## 5. 시추 (DIG)
### 5-1. 격자와 칸
- 칸 종류와 곡괭이 등급(이번 단계 등급 1 고정, 바위까지 뚫림 / 단단한 바위·고대석은 못 뚫음 → 빨간 X 표시):

| 칸 | 뚫는 시간 | 비고 |
|---|---|---|
| 흙 | 0.6초 | |
| 바위 | 1.5초 | |
| 단단한 바위 | ✕ | 등급 2부터 |
| 고대석 | ✕ | 등급 3부터 |
| 광맥(구리·은·금·보석·발광) | 1.0초/칸 | 광맥 덩어리 크기 3~20칸, 캐면 창고로 |
| 지하수 | 0.6초 | 뚫는 순간 아래 연결된 갱도 **침수**(§7) |
| 가스 주머니 | 0.6초 | 뚫는 순간 30초 채굴 정지(§7) |
| 유물 상자 | 1.0초 | 열면 유물 1(이번 단계: 금화 50~200 + 도감 아이콘) |
| 빈 공간(동굴) | 0초 | 공짜. 10%로 갱도 몬스터 1(이번 단계는 광차 되돌림만, 전투 없음) |

- 생성: 깊이에 따라 광종 비율(뒷산: 구리 50 · 은 30 · 금 15 · 보석 4 · 발광 1 → 깊이 ×1.5 가중). 광맥 덩어리는 셀룰러 성장. 빈 공간 3~5개, 유물 0~1, 지하수·가스는 힌트대로.

### 5-2. 갱도 그리기
- 손가락을 **격자 위에서 연속 드래그** → 상하좌우 연속 경로(대각선 안 됨). 시작점은 지상에 닿은 칸이거나 이미 뚫린 칸. 경로 미리보기 = 반투명 주황 선 + 칸별 예상 시간 합계 표시. 손을 떼면 확정 → 광부들이 순서대로 판다.
- 못 뚫는 칸이 경로에 있으면 그 칸에서 끊고 나머지는 취소(빨간 X 0.6초).
- 광부 3명: 한 명이 경로 선두에서 곡괭이질, 둘은 뒤에서 따라오며 **캔 광석을 광차까지 나른다**(들고 걷기 애니 = walk + 머리 위 광석 아이콘). 광부 수·역할은 다음 명세에서 건물로.
- 경로가 광맥에 닿으면 광맥 전체가 **채굴 대상**이 되어 광부가 자동으로 다 캔다(플레이어가 칸마다 안 그려도 됨). 광맥 덩어리 캐는 동안 그 덩어리 테두리가 금색으로 깜빡.
- 중력 §1 적용.

### 5-3. 광차
- 광차 1대. 지상 창고 ↔ 갱도 선두 사이를 **레일 자동 부설**(뚫린 경로에 레일이 깔림)로 왕복. 적재 8칸분, 속도 2칸/초. 광부가 캔 광석은 광차에 쌓이고, 가득 차거나 광맥이 끝나면 지상으로 올라가 창고에 붓는다(숫자 튀어오름 → HUD로 빨려감).
- **창고 용량 60**(이번 단계 고정). 꽉 차면 광차가 지상에서 멈추고 광부가 팔짱 끼고 말풍선 "창고가 꽉 찼어요!" → 판매 압박.

### 5-4. 큰 광맥 연출
- 덩어리 ≥ 12칸에 처음 닿을 때: 슬로모 0.4초 + 화면 플래시 + 종 + "대박!" 텍스트 + fx `jackpot`. 결과 카드에 기록.

## 6. 광부 (이번 단계 최소)
- 광부 3명 고정: 붉은 수염(선두 채굴) · 뚱보(운반) · 금발(운반, 손 랜턴 = 이동 광원). 체력 3. 낙하·가스로 0이 되면 지상에서 10초 쉼. 사망 없음.
- [광부] 탭: 3명 카드(이름·상태·체력 ♥♥♥). 이번 단계는 보기만.

## 7. 사건 (라운드당 0~2, 20~60초 간격 랜덤, 조건 충족 시)
| 사건 | 조건 | 효과 | 해결 |
|---|---|---|---|
| 갱도 붕괴 | 뚫린 칸 ≥ 15 | 경로 중 연속 2~3칸이 흙으로 메워짐(fx `collapse`) + 그 위 캐릭터 낙하 | 다시 그리면 됨(흙 0.6초) |
| 지하수 | 지하수 칸 뚫음 | 그 칸에서 아래로 연결된 뚫린 칸들이 **물**로 참(fx `water`). 물 칸은 걷기 속도 ½, 광차 못 지남 | [펌프] 버튼(이번 단계: 금화 30, 5초 뒤 물 빠짐) |
| 가스 | 가스 칸 뚫음 | 30초 채굴 정지, 광부 기침 말풍선, 화면 가장자리 초록 비네팅(fx `gas`) | 기다림. 랜턴 불꽃이 가스에 닿으면(랜턴을 가스 칸 2칸 안으로 끌면) **폭발**: 주변 3×3 흙·바위가 뚫림 + 광부 체력 −1 — 위험한 꼼수 |
| 갱도 몬스터 | 빈 공간 뚫음 10% | 광차가 그 구간을 못 지나 되돌아옴 + 말풍선 | 이번 단계: 10초 뒤 사라짐(다음 명세에서 포탑) |

## 8. 판매 (SELL 탭) — R2
- 매입자 2: **브로크**(구리·은 +15%, 금·보석·발광 −10%) / **떠돌이 상인**(반대). 탭 상단에 매입자 토글.
- 시세: 광종별 기준가(구리 8 · 은 18 · 금 40 · 보석 90 · 발광 55) × 변동 계수. **10초마다** 계수 ×(1 ± 3~12%) 랜덤 워크, 0.5~2.0 사이로 클램프, 평균 회귀 0.02/틱.
- **급등 이벤트**: 하루 1~2회, 30초 전에 모모 편지(알림 틀) "오늘 저녁 상인이 보석을 비싸게 산대요" → 해당 광종 계수 ×1.8이 40초 지속. 알림 시점부터 그 광종 행이 UI 펄스.
- 행: 아이콘 · 보유 수 · 현재가 · 최근 2분 막대 8개(이미 있음) · [팔기]. 하단 [절반] [전부 팔기]. 팔 때 금화 숫자가 튀어 HUD로.
- 창고에 두는 것도 선택(창고 용량 안에서).

## 9. 라운드 결과 (RESULT)
- 조건: [철수] 버튼(확인 시트 "남은 광맥 n칸은 광부들이 계속 캐요" — 방치는 다음 명세라 이번엔 문구만) 또는 광맥 전부 고갈.
- 결과 카드(양피지 틀): 낙찰가 → 매출 → **순이익**(크게) · 최대 광맥 · 유물 · 걸린 시간 · 별 1~3(순이익/낙찰가 ≥ 0.5 / 1.5 / 3.0) · 사건 기록. 할아범 한마디(순이익 등급별 대사 3종).
- [다음 경매] → AUCTION. 통계 누적(라운드 수·총 순이익·최대 광맥) → 저장.

## 10. 세로 화면 구성 (폰)
```
[HUD: 금화 · 창고 n/60 · 날짜/시각]                 ← 상단 고정
[지상 띠: 창고 건물 · 두더지 · 광차 출입구]
[격자 12칸 × 보이는 12줄, 세로 스크롤]              ← 가운데, 엄지 영역
[알림 틀 (말풍선·편지) — 격자 위에 겹침]
[하단 시트: 탭 판매 / 광부 / 설정, 높이 32%]        ← 접으면 10%
```
- 경매·결과는 격자 위를 덮는 **전체 카드**(양피지). 패드·PC: 격자 가운데(칸 = 높이/14), 좌 패널 = 광부·사건 로그, 우 패널 = 판매.

## 11. 튜토리얼 (첫 라운드만, 모모 말풍선)
1 "경매에서 구획을 골라요. 힌트 아이콘을 보세요" → 2 "두더지가 킁킁대는 곳 아래에 광맥이 있어요" → 3 "손가락으로 갱도를 그려 보세요(흙만 뚫려요)" → 4 "광맥에 닿으면 광부들이 알아서 캐요" → 5 "창고가 차기 전에 [판매] 탭에서 팔아요. 시세는 계속 변해요" → 6 "다 캤으면 [철수]. 순이익이 점수예요". 각 단계는 해당 행동을 하면 넘어감.
