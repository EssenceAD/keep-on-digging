# v1.2 패치 — 화면 구성·글자·조작 전면 정리 (형철 폰 플레이 16:48)

> "텍스트 박스 줄이고 게임 화면 크게 · 가로모드 꽉 차게 · 해상도별 반응형 · 글자 정보량 많고 작아서 안 읽힘 · 화살표 너무 크고 ▲가 없어 내려가면 못 돌아옴 · 회사 화면 마을 더 크게 + 메뉴 직관적 · 튜토리얼 금 팔 때까지 멍 · 업그레이드 메뉴 복잡"
> 원칙 3개: **① 게임 화면이 주인공(화면의 60% 이상) ② 글자는 두 크기만 ③ 한 번에 보이는 글자 덩어리 ≤ 3개**

## 1. 레이아웃 시스템 (세로·가로·PC 모두 한 규칙)
화면을 **HUD 띠 / 게임 / 시트** 세 띠로만 나눈다. 비율은 방향별:

| | HUD | 게임 | 시트(접힘) | 시트(펼침) |
|---|---|---|---|---|
| 세로 폰 | 7% | **63%** | 6% (탭 줄만) | 40% (게임 위로 덮음, 게임은 뒤에 보임) |
| 가로 폰·패드 | 왼쪽 세로 띠 12% | **가운데 76%** | 오른쪽 12% (아이콘 탭) | 오른쪽 32% (게임이 밀리지 않고 덮음) |
| PC | 위 6% | **가운데 70%** (폭 = min(화면폭, 높이×1.4)) | 오른쪽 24% 상시 | — |

- **회전 시 즉시 재배치**(`resize`/`orientationchange`), 저장 없이. 가로일 때 갱도 격자는 16줄이 다 들어가게 칸 = 높이×0.76/16.
- 게임 영역은 **항상 정수 배율**(갱도 칸·부지 장면·사무소). 남는 건 어두운 테두리가 아니라 **게임 쪽으로 양보**(칸을 한 단계 키움) — 여백 ≤ 8%.
- 시트는 **반투명 덮개**(게임 70% 보임), 손잡이 끌어 접기/펼치기, 게임 탭하면 접힘.
- HUD 한 줄: `💰 56  📦 21/120  🕒 1일 12:32  [특성1] [회사]` — 끝.

## 2. 글자 — 두 크기만
- **본문 1종(16 UI px 이상)** · **제목 1종(22)**. 그 밖의 크기 금지. 지금 "적재 10→12 · 속도 3→3.5 · 2대" 같은 8px 부제 **전부 삭제**.
- 한 화면에 글자 덩어리(문장·목록) **3개 이하**. 넘으면 아이콘으로 바꾸거나 다음 탭으로.
- 숫자는 아이콘+숫자(`⛏ Lv2`, `💰 800`), 설명은 눌렀을 때만 툴팁 1줄.
- 튜토리얼·안내 말풍선: 초상 48px + **한 문장(최대 2줄)**, 폭 = 게임 폭, 높이 ≤ 게임 높이 15%. 상단 고정 안내줄("땅을 톡 = 갱도 입구…")은 **삭제** — 튜토리얼이 가르치고 설명서에 둔다.

## 3. 시추 조작
- 방향키: `◀ ▲ ▶` 한 줄 + `▼` 아래, **총 4개**, 각 40 UI px(지금 56), 게임 영역 **오른쪽 아래 구석** 반투명. 갱도 머리가 멈춰 "다음 어디?"일 때만 **살짝 커짐+노란 테두리**, 파는 중엔 60% 투명.
- **▲ 추가**: 위로 파기(사다리 자동). 지상이면 비활성.
- 광부가 막혀서 멈추면 방향키 위에 **이유 1줄**("단단한 바위 — ⛏ Lv2") + 그 줄을 탭하면 장비 탭의 그 항목으로.
- 입구 세우기: 지상 칸 탭 → 반투명 입구 미리보기 0.3초 → 확정. 두 번째 입구는 "입구 2/2" 작은 표시.
- 격자 위 진동계·투시 버튼은 **아이콘만**(📡2 🔦2), 왼쪽 위.

## 4. 회사 화면
- 세로 폰: 부지 장면 **3×**(1152 폭, 좌우 끌기, 처음 사무소 중앙), 높이 672 → 게임 63%에 맞춰 **위아래 잘라 보이기**(세로 스크롤 허용). 가로·PC: 2× 또는 3× 꽉 차게.
- 건물 목록 시트 → **아이콘 격자**: 건물 10개를 64px 아이콘(건물 그림 그대로) 2줄로, 아래에 `Lv1 · 💰150`만. 아이콘 탭 → 그 건물 **카드 1장**(그림 크게 · 효과 한 줄 · [올리기 💰150] 또는 [짓기]). 긴 목록 삭제.
- 부지 위 건물을 **직접 탭해도 같은 카드**. 빈 터 탭 → 짓기 카드.
- 장식·어울림은 카드의 작은 탭. "빈 터 6/10" 띠 → HUD 옆 작은 아이콘.

## 5. 장비(업그레이드) 메뉴 — 직관적으로
- 지금의 2열 글자표 → **아이콘 타일 2줄 × 5**: ⛏ 곡괭이 · 🚃 광차 · 🏠 숙소 · 📦 창고 · 🐾 꼬물 / 📡 진동계 · 🔦 랜턴 · 🔥 제련 · 💧 펌프 · 🔫 포탑. 타일에 **아이콘 + Lv 점 5개(●●○○○) + 가격**. 살 수 있으면 노란 테두리, 금화 부족이면 회색.
- 타일 탭 → 카드 1장: 큰 아이콘 · "흙 0.45→0.35초 · 바위 뚫림" 한 줄 · [올리기 💰800]. 두 번 탭 안 하게 **길게 누르면 바로 구매**.
- 회사 건물 카드와 **같은 카드 컴포넌트**(한 표니까).

## 6. 튜토리얼 템포 (멍 때림 제거)
- 기다리는 단계(광차 운반·판매 대기·광맥 다 캐기)는 **조건을 느슨하게**: "광차 1회 도착" → "광석 1개 창고 도착", "다 캐기" → "광맥 3칸 캐면 다음". 튜토리얼 구획은 광맥 칸 수 절반, 채굴 속도 ×2.
- 각 단계 **8초 넘게 기다리면** 모모가 "기다리는 동안 광부들이 알아서 캐요 — 이게 방치예요" 한 줄(멍을 설명으로 바꿈), 15초면 자동 진행 가능한 건 자동 진행.
- 금 판매 단계: 금 1개만 캐면 바로 판매로.
- 18단계 → **12단계**로 합침(진동계·입구2·장비·특성은 각 1단계로 묶고 나머지는 "처음 만나는 순간" 안내로 이동).

## 7. 결과 카드
- 글자 12줄 → **6줄**: 순이익(크게) · 별 · 최대 광맥 · 시간 · [특성 찍기] [다음 경매]. 낙찰가·매출·사건·과제는 카드 하단 작은 "자세히 ▸" 접힘.

## 8. 경매·탐사 화면도 같은 규칙
- 경매 입찰 화면: 구획 그림 55% · 나/상대 25% · 버튼 20%. 글자 덩어리: 예상 가치 1 · 현재가 1 · 길드 말풍선 1.
- 탐사: 도구 아이콘 3개 + [시추 시작] 하나.

## 9. Code 순서 (단계마다 배포)
1 레이아웃 시스템(§1)+회전 → 2 글자 규칙·안내줄 삭제·말풍선 축소(§2) → 3 방향키 4개+▲(§3) → 4 장비 아이콘 타일+카드(§5) → 5 회사 3×+아이콘 격자+같은 카드(§4) → 6 튜토리얼 12단계·템포(§6) → 7 결과 카드·경매·탐사(§7·8). 세로·가로·PC 스크린샷 각 3장.
