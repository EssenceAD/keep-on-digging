## 2. 사무소 내부 아트 교체 (형철 "도트 퀄이 레퍼런스보다 너무 떨어짐")
- 지금 쓰는 `art/office/office.px.js`는 **코드로 그린 임시본**(v0.8 §5 "임시 아트 금지" 위반). GPT 산출 `art/raw/mine_office_interior.png`(256×224 원본, 5배 확대본)로 교체:
  - `png2pxl.py --cols 256 --rows 224 --clean` → `art/office/office_gpt.px.js`의 `sprite("office_base")`.
  - pxl로 얹는 것만: 벽난로 `_fire_lamp` + 불꽃 anim(불 영역을 원본 색으로 찾아 그 위에), 책상 램프 `_desk_lamp`, 선반 발광석 `_ore_lamp`, 창문 달빛 lamp, `lighting ambient 0.42`(no_magic_night와 동일), glow. 인수인계 장면은 낮 버전(lighting 없이 원본 + 벽난로 glow만).
  - 캐릭터(할아범·붉은 수염)는 이미 치비 스프라이트 → 그대로 배치. 할아범은 책상 뒤 의자에 **앉은 포즈**가 필요 — 서 있는 치비의 다리를 책상에 가려서 앉은 것처럼(책상 뒤 레이어).
- 확대 배율: PC에서도 **정수 배율**(4× 또는 5×)로, 남는 영역은 어두운 테두리. 지금처럼 화면 꽉 채우려고 비정수 확대하면 픽셀이 뭉개짐 — 이것도 "퀄 떨어져 보임"의 원인.
