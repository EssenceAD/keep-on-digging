# v1.9 패치 — 처음 10분 동선 (Claude가 새 계정으로 직접 플레이해서 찾은 것, 10/24 23:50)

> 형철: "바뀐 시스템 적응이 아예 안 됨. 판매탭 누르면 안 열림."
> Claude가 빈 저장(새 브라우저)으로 v1.8.1을 처음부터 해 봄. 시스템 자체보다 **처음 10분이 끊겨 있는 게** 원인. 아래 순서대로 고치고, §9 자동 플레이로 확인.

## 1. 첫 5분이 "할 게 없음" — 가장 큰 문제
- 시작 금화 30 < 곡괭이 40, 그리고 **[다 팔기]는 해금 #3(창고 첫 가득)까지 잠김** → 창고 60칸이 차는 5분 동안 팔 수도 업글할 수도 없음.
- 고침: **판매는 처음부터 항상 가능**(창고 카드에 [다 팔기]·광종별 [팔기] 상시). 해금 #3은 "창고 업글 해금 + 모모 한 줄"만. 시작 금화 30 → **60**(첫 곡괭이 즉시 구매).

## 2. "판매 탭" 버튼이 아무 데로도 안 감 (형철 제보 버그)
- 부지 화면 창고 카드의 [판매 탭] → 카드만 닫힘. 부지 아래 패널엔 「건물」 탭 하나뿐이라 갈 곳이 없음(판매 탭은 광산 화면 오른쪽 패널에만 있음).
- 고침: 부지에선 **창고 카드 자체가 판매 화면**. [판매 탭] 버튼 삭제 → 광종 줄마다 오른쪽에 [팔기] + 아래 [절반] [다 팔기] + 상회 바꾸기(브로크/상인) 한 줄. 광산 화면 오른쪽 판매 탭은 그대로.

## 3. 해금 말풍선이 안 뜸
- 해금되면 "!"에만 쌓이고 화면엔 아무것도 안 나옴 → 새 사람은 뭘 해야 할지 모름("탭해서 곡괭이부터 갈아요!"를 "!" 눌러야 봄).
- 고침: 해금 순간 **화면 아래 모모 말풍선 3초 + 해당 건물 반짝 + 손가락(ui_hand) 한 번**(명세6-3 §1·§4 그대로). "!"는 다시 보기용.

## 4. 새 시스템용 첫 안내 5단계 (옛 12단계 시추 튜토리얼 대체)
| # | 말풍선(모모 한 줄) | 손가락 | 넘어가는 조건 |
|---|---|---|---|
| 1 | "대장간을 눌러서 곡괭이를 갈아요!" | 대장간 | 곡괭이 Lv2 |
| 2 | "광석이 쌓였어요. 창고에서 팔아요" | 창고 | 첫 판매 |
| 3 | "더 갈수록 빨라져요. 한 번 더!" | 대장간 | 곡괭이 Lv4 |
| 4 | "광차가 밀려요. 광차 차고를 올려요" | 광차 차고 | 광차 Lv2 |
| 5 | "갱도 입구를 누르면 광부와 원정이 있어요" | 갱도 입구 | 갱도 창 열기 |
- 첫 원정(해금 #5)에서만 시추 안내 **4단계**: 꼬물이 킁킁 → 땅 탭(입구) → 방향키 → [탐사 끝·갱도로 삼기]. 옛 `1/12` 안내는 삭제.

## 5. 첫 원정이 지도를 건너뜀
- [첫 원정 떠나기] → 바로 옛 시추 화면(옛 지상 그림 + 옛 12단계 안내)으로 들어감. 지도·싼 땅 구매를 안 거침.
- 고침: 첫 원정도 **지도 → 싼 땅 [사기] → 원정**. 첫 지도엔 싼 땅만(보통·노른자는 해금 #8부터).

## 6. 빈 터 "무엇을 지을까요?" 가격이 `unde…`(undefined)
- 빈 터를 누르면 건물 4개 가격이 전부 `💰unde…`. 6-1에서 회사 건물 비용표를 엔진 업글로 옮기면서 끊긴 것으로 보임.
- 고침: 짓기 가격 = 그 건물 엔진 업글 Lv1 비용. 잠긴 건물은 자물쇠 + 해금 조건 한 줄.

## 7. 작은 것들
- **[광산] 버튼(오른쪽 위)**: 라운드가 없을 때 눌러도 반응 없음 → 라운드 없으면 **갱도 창**을 엶.
- **생산 표시 반올림**: HUD는 0.5/초인데 실제 0.45라 "생산 0.5/초이면 원정"이 안 열림 → 1 미만은 소수 둘째 자리(0.45/초)로.
- **돌아오셨군요 카드**: "자리 비운 동안 광석 0개 · 창고 60/60 가득" → 실제로 창고에 들어온 개수를 셈.
- **갱도 창 글자 과다**: 생산 순위 4줄은 게시판으로 옮김, 십장 버튼은 해금 #10 전엔 숨김. 남는 것: 갱도 목록 · 광부 ± · [원정].
- **부지에 생산이 안 보임**: 광부 셋이 모닥불 앞에만 서 있음 → 엔진 가동 중엔 광부가 갱도 입구로 들어갔다 나오고(4~8초 간격), 광차가 입구↔창고 왕복(명세6-1 §6).

## 8. 광산 화면 지상 그림 (Claude 담당 — 같은 날 올림)

## 9. 완료 조건 — 자동 플레이로 확인 (Claude가 쓴 방식 그대로)
- Playwright로 **빈 저장 새 브라우저**에서: 인트로 건너뛰기 → 안내 5단계를 손가락 위치 클릭만으로 끝까지 → 창고 판매 → 첫 원정(지도→싼 땅→시추→갱도로 삼기)까지 가면서 단계마다 스샷. 막히는 곳(손가락이 가리키는데 눌러도 안 되는 곳) 0개.
- 시간 빨리감기는 저장의 시각 값(`idle.lastSeen`·`savedAt`·`engine.lastTick`)을 페이지 로드 전에 N분 당기는 방식(`addInitScript`)이 잘 됨.
