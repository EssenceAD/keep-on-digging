# 「용사님, 채굴하실게요~」 — 1단계 명세 (v1 · 2026-10-24)

> 체크인(모험의 유산) 세계관 스핀오프 **아이들러**. 텀오일의 「라운드·불확실성·팔 타이밍」 + 킵온마이닝의 「방치해도 자라는 숫자」.
> 영문 가제: **Keep On Digging** / 저장소 가제 `keep-on-digging`.

## 0. 원칙
- **욕심 금지.** 핵심 재미 3개에 직접 기여하지 않는 건 1단계에서 안 만든다.
  - **R1 "저 밑에 뭐가 있을까"** — 경매·탐사·시추의 불확실성, 큰 광맥 터지는 순간
  - **R2 "지금 팔까 말까"** — 시세 변동, 창고에 쌓아 두는 손맛
  - **R3 "들어오니 쌓여 있네"** — 방치 채굴, 접속 첫 행동이 "시세 보고 팔기"
- 체크인 시스템은 **코드째 재사용**(아래 §7). 게임 본체(라운드)만 새로 짠다.
- 그래픽은 **HD-2D**(별도 `MINING_VISUAL_1024.md`). 도트 캐릭터 유지 + 빛·입자·깊이.
- **세로 모드 기본**(2026-10-24 확정 — "가로모드 강요 안 했으면"). 폰 세로가 1순위, 패드·PC는 같은 세계를 더 넓게 보여 주는 식으로 **반응형**. 방향 잠금·회전 강요 없음.
  - 세로(폰): 격자 12칸이 화면 **가로를 꽉 채움**(칸 = 너비/12 → 390px 폰에서 32px). 16줄 = 512px라 **격자 전체가 한 화면에 들어감**(스크롤 불필요). 위에 지상 띠 + HUD, 아래에 판매·행동 시트.
  - 가로/패드/PC: 칸 = min(너비/12, 높이/18) — 격자를 가운데 세우고 남는 좌우에 창고·시세·사건 로그 패널. 세계는 같고 UI 배치만 바뀜.
  - 터치 영역 44px 이상. 드래그로 갱도 그리기는 세로에서 엄지로 되게(격자가 화면 아래쪽 2/3에).

## 1. 세계관 · IP 연동
- 여관 마을 뒷산의 **드워프 광산 회사 「돌망치 상회」**. 사장 드워프 「돌망치 할아범」이 은퇴하며 플레이어에게 넘긴다(체크인 버나드 패턴).
- 등장: **모모**(여관 심부름 — 편지·공지), **버나드**(가끔 구경), **브로크**(대장간 — 광석 매입자 1), **떠돌이 상인**(매입자 2), **꼬마 두더지**(탐사 펫 — 체크인 펫 재활용).
- 경쟁 AI 길드 3곳: 「심연낚시 동호회」 「탑오르는중」 「방패장인 조합」 (체크인 AI 길드 이름 재활용).
- **크로스 보상(2단계)**: 채굴 게임 주간 순이익 등급 → 체크인 우편으로 「강화 가루」 쿠폰 / 체크인 평가 등급 → 채굴 게임에 「드워프 장식」. 1단계는 **같은 계정(Supabase 로그인) 공유**까지만.

## 2. 라운드 (R1 · R2) — 광맥 하나 = 5~8분

### 2-1. 경매 (아침)
- 매일(게임 속 하루 = 현실 24분 · 체크인 clock 재사용) 아침에 **구획 3곳**이 나온다. 구획 카드: 크기(S/M/L) · 지형 힌트 아이콘 2개(바위 많음 🪨 / 물길 💧 / 유적 흔적 🏺 / 발광 이끼 ✨) · 시작가.
- 입찰: AI 길드 3곳이 각자 성향으로 호가(공격적/신중/랜덤). 플레이어는 **호가 3단계(+10% / +25% / +50%)** 중 하나 또는 포기. 2라운드 입찰 후 최고가 낙찰.
- 힌트 → 실제 생성 규칙: 🪨 바위층 40% / 💧 지하수 1~2 / 🏺 유물 상자 1 확정 / ✨ 발광 광석 확률 ×3. 힌트는 **진실이지만 전부가 아님**(힌트 없는 요소도 생성됨).

### 2-2. 탐사
- 구획에 들어가면 지상에서 **꼬마 두더지**가 좌우로 돌아다니며 가까운 광맥 위에서 킁킁(이모트 + 소리). 깊이는 모른다(텀오일 다우저).
- 장비 「투시 랜턴」(업그레이드)이 있으면 탭한 지점 아래 **3×3 칸**이 흐릿하게 보인다(하루 n회).

### 2-3. 시추
- 격자 지하(가로 12 × 세로 16칸). 손가락으로 **갱도 경로를 그린다**(연속 드래그 · 상하좌우 · 대각선 없음). 곡괭이 등급보다 단단한 칸(바위/단단한 바위/고대석)은 못 뚫음.
- 칸 종류: 흙 · 바위 · 단단한 바위 · 고대석 · **광맥**(철·구리·은·금·보석·발광 광석 — 크기 3~20칸) · 지하수(뚫으면 아래 갱도 침수 → 펌프 필요) · 가스 주머니(뚫으면 30초 채굴 정지) · 유물 상자 · 빈 공간(동굴 — 공짜로 뚫림 · 가끔 갱도 몬스터).
- 광맥에 닿으면 **광차 왕복 시작**: 광차 1대당 n초마다 광석 1칸분 운반 → 지상 창고. 광차 수·속도 업그레이드.
- **큰 광맥(12칸 이상) 터질 때**: 슬로모 0.4초 + 플래시 + 종소리 + "대박!" (틱폴 전설 드랍 문법).

### 2-4. 판매 (R2)
- 매입자 2곳: **브로크 대장간**(철·구리·은 선호) / **떠돌이 상인**(금·보석·발광 선호). 광종마다 **시세가 10초마다 ±3~12% 랜덤 워크**, 하루 1~2번 **급등 이벤트**(모모 편지로 예고 30초 전: "오늘 저녁 상인이 보석을 비싸게 산대요").
- 창고 용량 제한(업그레이드). 꽉 차면 광차가 멈춘다 → **팔아야 한다**는 압박.
- 판매 화면: 광종별 칸 · 현재가 · 최근 2분 그래프(막대 8개) · [전부 팔기] [절반] [보류]. 시세가 오르는 중이면 UI가 "띵" 하고 커진다.

### 2-5. 사건 (라운드당 0~2)
- **낙하**(발밑 칸이 뚫리면 광부·광차·두더지가 떨어짐 — 명세2 §1, v0.4 버그를 규칙으로) · 갱도 붕괴(그린 경로 일부 메워짐 — 다시 그리면 됨) · 지하수 · 가스 · **갱도 몬스터**(체크인 사냥 몹 재활용 — 광차에 단 포탑이 자동으로 쏨, 포탑 등급 < 몬스터면 광차가 되돌아옴) · 유물 상자(수집 꾸러미 §7).

### 2-6. 라운드 종료
- 광맥을 다 캤거나, 플레이어가 「철수」를 누르면 종료. 결과 카드: 낙찰가 → 매출 → **순이익** · 최대 광맥 · 유물 · 걸린 시간 · 별 1~3(순이익/낙찰가 비율).
- 다 캐지 않은 광맥은 **방치 채굴 대상**으로 남는다(§3).

## 3. 방치 층 (R3)
- 종료 라운드의 남은 광맥은 광부들이 **현실 시간 기준** 계속 캔다: 분당 `광부 수 × 곡괭이 등급 × 0.5칸`, **최대 4시간분**(업그레이드로 8시간).
- 접속하면 **「돌아오셨군요」 카드**: 쌓인 광석 · 지금 시세 · [지금 팔기] [창고에 두기]. 이게 접속 첫 행동이다.
- 광맥은 고갈된다 → 새 라운드를 돌아야 방치 수입이 유지된다.
- 체크인 `world/offline.ts` 정산 구조 재사용.

## 4. 회사 (라운드 사이)
- 지상 부지(슬롯 격자 6×4 → 코어 레벨마다 확장)에 건물:

| 건물 | 효과 |
|---|---|
| 사무소(코어) | 메인 레벨 1~5 · 경매 구획 크기·층 해금 |
| 창고 | 용량 |
| 제련소 | 광석 → 괴(가격 ×1.6, 시간 소요) |
| 광차 차고 | 광차 수·속도 |
| 광부 숙소 | 광부 수(방치 속도) · 광부들이 걸어 다닌다 |
| 랜턴 공방 | 투시 랜턴 횟수·범위 |
| 펌프실 | 지하수 처리 |
| 포탑 공방 | 광차 포탑 등급 |
| 두더지 집 | 탐사 정확도 |
| 장식 | 어울림(체크인 harmony 재사용 — 예: 숙소+모닥불 = 광부 속도 +10%) |

- **특성 트리**(킵온마이닝): 회사 레벨업 포인트로 영구 패시브 3갈래 — 「탐사」(힌트 정확도·랜턴) / 「채굴」(곡괭이·광차) / 「장사」(시세 미리보기·판매가 +%).

## 5. 층 · 끝
- 뒷산(철·구리) → 폐광(은·금·몬스터) → 지하 호수(보석·지하수 많음) → **고대 드워프 도시**(발광 광석·고대석·유물). 사무소 레벨로 해금.
- 엔딩: 드워프 도시의 「왕의 금고」 구획(특별 경매)을 낙찰·개방하면 엔딩 + 회차(새 산: 시세 변동 폭 ↑, 힌트 ↓).
- 1단계는 **뒷산 + 폐광 2층**.

## 6. 주간 리듬 (체크인 재사용)
- **주간 시세 테마**(평가 시즌 코드): 철 주간·보석 주간… 해당 광종 기본가 ×1.5.
- 주간 랭킹(rank 코드): 순이익 · 최대 광맥 · 유물 수. 월요일 0시 KST 초기화.
- 일일 과제(daybook): "경매 1번 낙찰 · 광석 500 판매 · 유물 1개".
- 이웃 광산 구경 + 방명록(neighbors·guestbook). 길드 공동 광산은 2단계.

## 7. 체크인에서 코드째 가져오는 것
`net/server.ts`(가입·로그인·복구코드·클라우드 저장·채팅·랭킹·제보 편지·공지) · `world/clock.ts`(게임 시계·낮밤) · `world/offline.ts` · `world/daybook.ts` · `world/evaluation.ts`(→ 시세 테마) · `world/harmony.ts` · `world/bundles.ts`(→ 유물 수집) · `world/pets.ts`(두더지) · `world/guestbook.ts` · `ui/notice.ts` · `ui/opsbox.ts`(운영 선물) · `ui/confirmSheet.ts` · 온보딩·설명서 틀.
- **새로 짜는 것**: 경매 · 지하 격자·시추 · 광차 · 시세 · 회사 건물표 · 특성 트리 · HD-2D 렌더러.
- Supabase: 체크인 프로젝트 **같은 프로젝트**에 `mine_` 접두 테이블(계정 공유 위해). 세이브는 `mine_saves`.

## 8. 1단계 완료 기준
1. 경매 → 탐사 → 시추 → 판매 → 결과 → 방치 → 재접속 카드까지 끊김 없음.
2. 뒷산·폐광 2층, 광종 5(철·구리·은·금·보석), 사건 4종, 몬스터 2종.
3. 건물 10종, 특성 트리 3갈래 × 5단.
4. 시세 랜덤 워크 + 급등 이벤트 + 주간 테마.
5. 로그인·클라우드 저장·채팅·주간 랭킹·제보 편지 동작(체크인 재사용).
6. HD-2D 비주얼 프로토타입 통과(별도 문서 §4) 후 본 개발.
7. 갤럭시 중급 폰 45fps · 저사양 모드 토글.

## 9. 수익
- 무료. 광고: 「시세 1분 미리보기」 · 「방치 상한 2배(이번 1회)」. 스킨: 광부 의상·광차·사무소 지붕. 능력치 판매 없음.

## 10. 작업 순서 (Code)
1. 저장소 세팅 + 체크인 공용 모듈 복사(§7) + Supabase `mine_` 테이블.
2. **비주얼 프로토타입**: 갱도 격자 1장 + 랜턴 조명 + 곡괭이 주스 + 광차 1대 → 웹 링크 (여기서 멈추고 형철 폰 확인).
3. 경매·탐사·시추·광차·창고·판매 루프(임시 아트).
4. 회사 건물·특성 트리·방치.
5. 사건·몬스터·유물·주간 리듬·랭킹.
6. 아트 교체(HD-2D 가이드) · 폰 성능.
