# v1.0 패치 — 회사 부지를 "장면"으로 (형철 13:20 "체크인 마을 퀄리티는 나와야")

> v0.9 회사 화면 = 초록 평면 + 건물 2개. 체크인 마을은 **땅·길·울타리·소품이 있는 디오라마**였고 건물은 그 위에 얹혔다. 여기도 같은 구조로 간다. **격자 슬롯 개념을 버린다.**

## 1. 배경 = GPT 그림 1장 (`art/raw/mine_yard_bg.png`, 384×216 원본)
- 뒷산 자락 캠프: 능선·소나무·하늘 / 풀 언덕 / 왼쪽→오른쪽 아래 갱도 입구로 이어지는 흙길 / 갱도 입구(돌·지지대·레일) / 울타리·개울·다리·바위·그루터기·들꽃·장작·우물 자리.
- 길 양옆에 **빈 터 10곳**(다진 흙 바닥 44×28)이 그림 안에 이미 있다. 이게 건물 자리. 슬롯 격자·좌표 입력 없음 — `art/yard_lots.json`에 10곳의 (x,y,w,h)를 Code가 그림 보고 적는다(위 5·아래 5).
- 변환: `png2pxl.py --cols 384 --rows 216 --clean` → `art/yard/yard_gpt.px.js` `sprite("yard_base")`. pxl이 얹는 것: 개울 물결 anim, 굴뚝 연기, 들꽃 흔들림 2f, 밤 lighting(창문·모닥불·갱도 입구 랜턴 lamp, ambient 0.4, 창문 L emit). 낮/밤은 게임 시계로 크로스페이드.

## 2. 건물 배치
- 건물은 **빈 터에만** 놓인다. [짓기]를 누르면 빈 터 10곳이 반짝이고 하나를 탭 → 그 자리에 건물 Lv1(`mine_buildings_lv1` 변환본). 옮기기는 빈 터끼리.
- 건물 밑에 그림자 타원 + 터 테두리 돌은 건물이 가림. 사무소는 **길 위쪽 가운데 터에 기본 배치**.
- 장식 6종은 빈 터가 아니라 **그림 속 정해진 소품 자리 12곳**(우물 자리·장작 자리·울타리 옆·개울가·갱도 입구 양옆…) — `yard_lots.json`의 `decoSpots`. 어울림 판정은 "같은 구역(위/아래/입구)"으로.
- 부지 확장(사무소 Lv): 터 10곳 중 **처음엔 6곳만 열림**(나머지 4곳은 덤불로 덮임, Lv2·3·4·5마다 1곳씩 덤불 걷히는 연출).

## 3. 사람·움직임 (체크인 마을처럼 살아 있게)
- 광부들은 숙소 ↔ 사무소 ↔ 갱도 입구를 **흙길 따라** 걷는다(길은 그림의 흙길 폴리라인 — `yard_lots.json`의 `path`). 밤엔 숙소 창문 불, 모닥불 옆에 앉기.
- 두더지는 두더지 집 앞 또는 길가에서 낮잠/킁킁. 광차는 갱도 입구에서 창고까지 레일(그림의 레일 위) 왕복이 보임.
- 모모가 편지 올 때 길 왼쪽 끝(다리)에서 걸어 들어와 사무소 앞에서 편지 흔들고 돌아감.
- 새 2마리·나비·낙엽 입자 조금.

## 4. 화면 구성
- **정수 배율**: 384×216을 PC는 4×(1536×864), 폰 세로는 너비 맞춤 정수(390px → 1× 384, 위아래 여백에 HUD·시트), 패드 2~3×. 남는 곳 어두운 테두리. 절대 비정수 확대 금지.
- 하단 시트(건물 목록)는 **접힌 상태가 기본**(10%), 펼치면 45%. PC는 오른쪽 패널로.
- HUD는 그림 위 반투명 띠 하나(금화·창고·날짜) — 지금처럼 좌우에 큰 패널 3개 쌓지 않는다. 광부 카드·과제·사건 기록은 **탭으로 접기**.

## 5. 기준
- 배포 전 `docs/ref/building_quality_2.png`(마을 군집)와 나란히 비교. "건물이 땅 위에 서 있다"는 느낌이 안 나면(그림자·터 테두리·길 연결) 배포 금지.
- `art/buildings.px.js`(코드 건물)·초록 평면·격자 슬롯은 **삭제**.

## 6. 순서
1 배경 변환 + lots.json → 2 건물·장식 배치 → 3 사람·움직임·밤 조명 → 4 화면 구성·HUD 정리 → 비교 스샷 → 배포.
