## 0. 완료 조건
1. 층 4개(뒷산·폐광·지하 호수·드워프 도시) + 엔딩 + 회차.
2. 이웃 광산 구경·방명록·채팅(체크인 재사용) — 체크인 유저끼리 서로 보임.
3. 체크인 ↔ 채굴 크로스 보상.
4. 유물 도감 + 수집 꾸러미.

## 1. 층 3·4
### 1-1. 지하 호수 (사무소 Lv4)
- 색온도 남색, 물결 반사(격자 아래쪽 1/3에 **물 띠**가 가로로 흐름 — pxl anim 타일, 조명 반사 glow). BGM `bgm_mine_3`.
- 생성: 보석 30 · 은 25 · 금 20 · 발광 15 · 구리 10. **지하수 칸 3~5**(힌트 없어도), 바위 보통, 고대석 등장(곡괭이 3 필요). 유물 확률 ×2.
- 새 사건: **홍수** — 지하수 2개 이상 뚫리면 호수 수위가 올라와 아래 2줄 침수(펌프 2회 필요). 새 몬스터: **동굴 게**(광차를 집어 멈춤 3초, 포탑 2).
- 새 칸: **수정 기둥**(뚫으면 보석 2 + 반짝 연출).
- 시작가 ×2.4.

### 1-2. 고대 드워프 도시 (사무소 Lv5)
- 색온도 황금/보라, 배경 패럴랙스에 **드워프 건축 실루엣**(기둥·아치·조각상 — GPT 1장 → png2pxl). BGM `bgm_mine_4`.
- 생성: 발광 35 · 보석 25 · 금 20 · 고대석 많음, **유물 상자 2~3 확정**, 빈 공간에 **유적 방**(3×3 빈 칸 + 유물 1 + 함정 1).
- 함정: 화살(광부 체력 −1) · 굴림돌(갱도 3칸 메움). 몬스터: **돌 골렘**(포탑 4, 아니면 광차 되돌림 + 갱도 1칸 메움).
- 시작가 ×4.

### 1-3. 왕의 금고 (엔딩)
- 드워프 도시에서 **별 ★3 라운드 3회** 달성 시 다음 경매에 특별 구획 **「왕의 금고」**(시작가 5,000, 길드 전원 공격적). 낙찰 → 격자 12×16 전체가 고대석+발광+유물 5, 중앙에 **금고 문**(곡괭이 3으로 20초).
- 문 열면: 엔딩 연출(황금 쏟아짐 + 할아범·모모·브로크·상인 등장 + 대사 6줄) + **엔딩 카드**(총 라운드·총 순이익·최대 광맥·유물 수·걸린 날).
- **회차**: [새 산으로] → 금화·창고·건물 Lv **유지**, 특성 유지, 층 해금은 **사무소 Lv 유지**이므로 그대로. 변하는 것: 시세 변동 폭 ×1.5, 힌트 −1, 길드 평가액 +20%, 광맥 크기 +20%, 유물 새 세트. 회차 뱃지(HUD 별). 랭킹은 회차별 분리.

## 2. 유물 · 도감 (체크인 `bundles.ts`)
- 유물 24종(층별 6): 이름·한 줄 설명·pxl 아이콘 24×24(GPT 시트 → 변환). 예: 뒷산 「녹슨 곡괭이 머리」「드워프 담뱃대」… 도시 「왕의 인장」.
- 꾸러미 4(층별): 6개 모으면 **영구 보너스**(뒷산: 흙 속도 +10% / 폐광: 포탑 +1 / 호수: 펌프 무료 1회/일 / 도시: 특성 포인트 +1).
- [도감] 탭(회사 화면): 유물·어울림·몬스터·칸 종류. 못 찾은 건 실루엣.

## 3. 이웃 · 방명록 · 채팅 (체크인 `neighbors` · `guestbook` · `net/server.ts` chat)
- 회사 화면 [이웃]: 같은 주 랭킹에 있는 유저 + 친구(체크인 친구 목록 그대로) 목록. 누르면 **그 사람 부지를 읽기 전용으로 구경**(건물·장식·Lv 눈금·방치 중인 광부 걸어 다님). 방명록 남기기(체크인 guestbook).
- 채팅: 체크인 채팅방 **공유**(같은 Supabase 채널 — 체크인·채굴 유저가 한 방). 메시지 앞에 작은 아이콘(🏨/⛏)으로 어느 게임에서 쓰는지.
- 제보 편지(체크인 letters) 그대로 — 설정 → [편지 보내기].

## 4. 크로스 보상 (명세1 §1)
| 방향 | 조건 | 보상 |
|---|---|---|
| 채굴 → 체크인 | 주간 순이익 등급(랭킹 상위 30% / 중 / 하) | 체크인 우편: 강화 가루 쿠폰 大/中/小 (월요일 0시 정산, 체크인 `mail` 테이블에 insert — 서버 함수) |
| 체크인 → 채굴 | 체크인 평가 시즌 등급 S/A/B | 채굴 모모 편지: 「드워프 장식」(S: 황금 동상 / A: 여관 간판 / B: 체크인 깃발) — 장식 슬롯용, 어울림 1개씩 |
- 양쪽 다 **한 계정**(같은 user_id) 기준. 수령은 각 게임에서 편지 열 때.

## 5. 광부 개성 (작게)
- 광부 3~6명 각각 이름·성격 한 줄(붉은 수염: 성급함 — 곡괭이 +10%, 낙하 ×1.5 / 뚱보: 느긋 — 운반 −10%, 가스 면역 / 금발: 꼼꼼 — 유물 발견 +20% / 추가 광부 3명은 랜덤 성격). 광부 탭에서 보기만, 숫자는 `balance.js`. **교체·고용 없음**(욕심 금지).

## 7. 운영 틀
- 패치 노트: 설정 → [새 소식] (체크인 notice 재사용). `docs/PATCH_NOTES.md`에서 읽음.
- 크레딧: 설정 → [만든 사람] — 형철 · Claude · 사운드 출처(freesound CC0 목록) · pxl(crsolver, MIT).
