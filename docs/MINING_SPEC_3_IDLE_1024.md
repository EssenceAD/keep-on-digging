# 「용사님, 채굴하실게요~」 — 3단계 명세: 방치 · 회사 · 특성 · 계정 (v1 · 2026-10-24 09:20)

> v0.5 핵심 루프 **통과**(형철 폰 확인). 이번 단계는 **R3 "들어오니 쌓여 있네"**와 **라운드 사이의 성장**이다.
> 끝나면 "며칠 동안 매일 들어와서 하는 게임"이 된다. 체크인(`legacy-of-adventure`) 모듈은 **코드째 복사**.

## 0. 완료 조건
1. 앱을 닫고 1시간 뒤 열면 **「돌아오셨군요」 카드**가 뜨고, 쌓인 광석을 그 자리에서 판다. 접속 첫 행동 = 시세 보고 팔기.
2. 라운드 사이에 **회사 화면**(지상 부지)에서 건물 10종을 짓고 올려서 다음 라운드가 눈에 띄게 달라진다(광차 2대, 창고 120, 광부 4명…).
3. **특성 트리** 3갈래 × 5단이 회사 레벨 포인트로 열린다.
4. 체크인 계정으로 **로그인·클라우드 저장**(같은 Supabase 프로젝트, `mine_` 테이블). 비로그인도 로컬로 계속 플레이 가능.
5. 경매 연출(길드 초상 + 호가 말풍선) · 2층 **폐광** 해금.

## 1. 방치 층 (R3)
### 1-1. 무엇이 쌓이나
- 라운드를 **[철수]**하면 남은 광맥 칸(`leftover`)이 방치 대상이 된다. 광부들은 **현실 시간**으로 계속 캔다:
  - 분당 채굴량 = `광부 수 × 곡괭이 등급 × 0.5칸` (3명·등급1 = 1.5칸/분 = 시간당 90칸)
  - `leftover`가 0이 되면 멈춘다 → **새 라운드를 돌아야 방치 수입이 유지**된다(이게 다음 날 접속 동기).
  - 상한 **4시간분**(숙소 Lv3부터 8시간). 상한 초과분은 버려짐 — 카드에 "광부들이 4시간 넘게 기다렸어요" 한 줄로 아쉬움 표시(광고 보상 자리, §7).
- 방치 중에는 사건 없음, 광차 용량 무시(단순화). 창고 용량은 **방치 수입에도 적용** — 창고가 꽉 차면 거기서 멈춘다 → 창고 업그레이드 동기.
- 라운드 **진행 중**(DIG 상태)에 닫았다가 돌아오면: 그 라운드는 **그대로 멈춰 있고**(실시간 진행 안 함), 카드 대신 "라운드 이어 하기" 토스트만. 방치는 철수한 뒤부터.

### 1-2. 「돌아오셨군요」 카드 (양피지 전체 카드, 할아범 초상)
```
돌아오셨군요!  (떠난 지 3시간 12분)
광부들이 캐 둔 것:  구리 ×48  은 ×30  금 ×12
지금 시세:         8 ↑     17 ↓     44 ↑        ← 행마다 화살표 + 어제 대비 %
예상 매출          384 + 510 + 528 = 1,422
[지금 팔기 1,422]   [창고에 두기]   [광종별로 고르기 ▸]
```
- [지금 팔기]: 현재 매입자 기준으로 전부 판매, 금화 숫자 튀어오름.
- [창고에 두기]: 창고로(용량 초과분은 자동 판매 + 안내).
- [광종별로 고르기]: 판매 탭으로 가되 방치분이 하이라이트.
- 카드 아래 작게: "다음 경매까지 n분" 또는 "오늘 경매 준비됐어요".
- 체크인 `world/offline.ts`의 정산 구조(마지막 시각·상한·요약 카드) 재사용.

### 1-3. 시세는 떠나 있는 동안도 움직인다
- 시세 랜덤 워크는 **결정론적**으로 재계산: `seed(day, 광종)` 기반 난수로 10초 틱을 빨리감기(최대 24시간 = 8,640틱, 즉시 계산). 그래야 "어제 금이 올랐대" 같은 대화가 성립하고 치트가 안 된다.
- 떠나 있는 동안 급등 이벤트가 있었으면 카드에 "어제 저녁 보석이 ×1.8 갔어요 (놓침)" — 다음엔 와야지 하는 마음.

## 2. 회사 화면 (라운드 사이)
### 2-1. 부지
- 지상 **슬롯 격자 6×4**(코어 Lv마다 +1열: Lv5에 10×4). 세로 폰에선 부지가 화면 위 55%, 아래 45%는 건물 목록 시트. 건물은 pxl 스프라이트(체크인 건물 톤, `art/buildings.px.js` — 아래 §2-3 목록으로 내가 초안 뽑음).
- 광부들이 부지를 **걸어 다닌다**(숙소 ↔ 사무소 ↔ 광산 입구), 두더지는 두더지 집 앞에서 낮잠. 밤이면 창문에 불.
- 진입: 결과 카드 → [회사로] / HUD 상단 **[회사]** 버튼(라운드 중에도 들어갈 수 있지만 건설은 라운드 사이에만 — 라운드 중엔 "광부들이 바빠요").

## 3. 특성 트리 (회사 Lv 포인트, 사무소 Lv당 +1 = 총 5점 + 라운드 ★3 10회마다 +1)
세로 폰: 3열 세로 트리, 각 5단. 1점씩, 위에서부터 순서대로.

| 단 | 탐사 | 채굴 | 장사 |
|---|---|---|---|
| 1 | 힌트 아이콘 3개 | 곡괭이 등급 2(단단한 바위) | 시세 1분 미리보기(점선) |
| 2 | 투시 랜턴 +1/일 | 흙 0.6 → 0.45초 | 판매가 +5% |
| 3 | 두더지 킁킁에 광종 색 | 낙하 기절 시간 ½ | 급등 예고 30 → 60초 전 |
| 4 | 경매 카드에 **광맥 총량 범위** 표시 | 곡괭이 등급 3(고대석) | 매입자 선호 페널티 −10% → −5% |
| 5 | 공짜 구획도 힌트 1개 | 광맥 닿으면 인접 광맥 자동 발견 | 하루 1회 **시세 고정**(10초→60초 동결, 팔 타이밍 보장) |

- 초기화: 금화 500(Lv1 때는 무료 1회).

## 4. 계정 · 클라우드 (체크인 `net/server.ts` 복사)
- **같은 Supabase 프로젝트**(`cwtxrcevrjeaiqqlqkds`). 테이블 접두 `mine_`: `mine_saves(user_id pk, data jsonb, updated_at)` · `mine_rank(user_id, week, profit, best_vein, relics, nickname)`. RLS는 체크인과 동일 정책 복사. 체크인 `profiles.nickname` 그대로 읽어 HUD에 표시 → **체크인 유저는 가입 없이 바로 자기 닉으로**.
- 로그인 UI: 설정 → [체크인 계정으로 로그인](이메일+비번·복구코드 — 체크인 그대로). 비로그인은 로컬 저장 유지, 로그인하면 **로컬이 더 진행됐으면 로컬을 올리고, 클라우드가 더 진행됐으면 묻기**(체크인 충돌 처리 재사용).
- 저장 시점: 라운드 종료 · 회사 변경 · 방치 정산 · 5분마다. `v`(스키마 버전) 마이그레이션 자리 둠.
- 주간 랭킹(체크인 `rank` 재사용): 순이익 · 최대 광맥 · 유물 수. 월요일 0시 KST 초기화. 설정 옆 [랭킹] 탭. 이번 단계는 **보기만**(보상은 명세4).

## 5. 경매 연출 + 폐광
- 경매: 길드 대표 3명 초상(`art/raw/mine_chibi_guilds.png` — 심연낚시·탑오르는중·방패장인, GPT 산출 예정) 카드 위에 서 있고, 호가 시 **말풍선 + 몸 흔들**, 패스 시 고개 젓기(flip 2f) + 회색. 낙찰 시 망치 쾅 + 종이 도장. 플레이어 호가 버튼은 하단 시트. 길드 대사 각 3종(공격적/신중/랜덤 성격 드러나게 — 내가 `docs/TEXT_GUILDS.md`로 줌).
- **폐광(2층)**: 사무소 Lv3에서 해금. 경매 카드에 층 표시. 생성: 은 35 · 금 30 · 구리 15 · 보석 12 · 발광 8, 단단한 바위 많음, 빈 공간 2배, 몬스터 2종(슬라임·박쥐떼 — 박쥐는 광부 1.5초 기절), 색온도 청록(비주얼 §3). 유물 확률 2배. 시작가 ×1.6.

## 9. Code 작업 순서 (단계마다 배포·알림)
1. 저장 구조 확장 + 체크인 `offline.ts` 포팅 → 방치 정산 + 돌아오셨군요 카드 + 결정론적 시세 빨리감기.
2. 회사 화면(부지·슬롯·건물 목록 시트) + 건물 10종 효과 연결(아트는 임시 박스 → 내 `buildings.px.js` 오면 교체).
3. 특성 트리 3×5 + 포인트.
4. 체크인 `net/server.ts` 포팅 → `mine_saves` 테이블(Supabase MCP로 생성, RLS 복사) → 로그인·동기화·충돌 처리 → 주간 랭킹 보기.
5. 경매 연출(초상·말풍선·망치) + 길드 대사 + 폐광 생성·몬스터 2종·포탑.
6. 일일 과제 + 광고 자리 버튼.
7. 세로·패드·PC 스크린샷, README, 배포.
