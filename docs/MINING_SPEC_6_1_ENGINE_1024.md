# 명세 6-1 — 엔진 (명세6 §3-1 · 5단계 중 1단계) "광산은 항상 돌아간다"

> 목표: 업글 → 초당 수입 ↑ → 다음 업글이 금방 → 또 ↑ 의 파도. 방치해도 창고가 차고, 돌아오면 "팔까 기다릴까"가 첫 결정.
> 이 단계에선 **원정(시추 플레이)은 그대로 두되 보상만 바꾼다**: 원정 끝 = 그 땅이 내 갱도가 됨(§3). 경매·특성·회차는 다음 단계.
> 숫자는 전부 `balance.js` 새 섹션 `engine` — 형철이 만진다. 아래 값은 첫 시안.

## 1. 상태 (저장)
```
engine: {
  mines: [{ id, name, rows, reserve, reserveMax, depth, oreMix:{C,s,g,j,c}, opened:day }],   // 소유 갱도
  pile: 0,              // 갱도 입구에 쌓인 광석(운반 대기). 상한 = engine.pileCap
  stock: {C,s,g,j,c},   // 창고 광석 (합계 ≤ 창고 용량)
  ingots: {C,s,g,j,c},  // 제련된 괴
  lv: { pick:1, lodge:1, cart:1, warehouse:1, smelter:0 },
  lastTick: 시각(ms)
}
```
- 첫 게임: 갱도 1개 「뒷산 1호」 (rows 10, reserve 1500, depth 1.0, oreMix 기본). 튜토리얼 원정 대신 이걸로 바로 시작.

## 2. 생산 사슬 (초 단위, 3단 병목)
1. **캐기** — 갱도마다 `캐기/초 = 배치 광부 × 곡괭이 속도 × depth`. 광부는 숙소 인원을 갱도들에 고르게(갱도 탭에서 ± 로 옮김). 캔 만큼 `reserve` 감소, `pile`에 쌓임. `pile`이 `pileCap`이면 캐기 멈춤(갱도 입구에 "가득" 표시).
2. **나르기** — `나르기/초 = 광차 수 × 적재 ÷ 왕복 시간`. `pile` → 창고. 창고 가득이면 멈춤(창고 위 빨간 "가득").
3. **팔기** — 창고 광석을 시세로 판다(수동: 창고 탭 → [다 팔기] / 광종별). 시세·두 상회·급등은 지금 그대로.
- 광종: 캔 광석 1개마다 그 갱도 `oreMix` 비율로 뽑음(깊을수록 귀한 쪽 가중은 depth로).
- 제련소(Lv ≥ 1): 창고 광석을 슬롯 수만큼 동시에 괴로(시간 `smeltSec`), 괴 값 = 광석 × 1.6, 괴는 시세 변동 ½.

## 3. 원정 → 갱도
- 원정(지금 경매+시추 라운드) 끝: 결과 카드에 **[갱도로 삼기]** 하나. 누르면 `mines`에 추가: `reserve = 캔 광맥 칸 수 × 30`, `oreMix` = 그 땅에서 실제 나온 비율, `depth = 1 + 판 최대 깊이 ÷ rows × 0.8`.
- 동시 운영 갱도 수 = 숙소 Lv 표 `mineSlots` (1, 2, 2, 3, 3, 4…). 꽉 차면 가장 고갈된 갱도와 바꾸기 선택.
- `reserve` 0 → 폐쇄(갱도 탭 회색 "다 캤어요") → 원정 동기.
- 원정 라운드 돈(라운드 중 판매)은 지금처럼 들어옴. 공짜 땅은 삭제(명세6 §3-2, 다음 단계에서 경매 수정).

## 4. 업글 — 무한형 (5단 표 폐기)
`비용(Lv) = 기본 × 배율^(Lv−1)` · 효과는 선형 + **Lv 10·25·50·100 에서 ×2** (도달 순간 크게 튀는 연출).
| 업글 | 건물 | 기본 비용 | 배율 | 효과(Lv) |
|---|---|---|---|---|
| 곡괭이 | 대장간(smelter 그림) | 40 | 1.15 | 광부 1명 캐기/초 = 0.10 × (1 + 0.25(Lv−1)) × 2^(마일스톤 수) |
| 숙소 | 숙소 | 150 | 1.22 | 광부 수 = 1 + Lv · `mineSlots` = 1 + ⌊Lv/3⌋ (최대 6) |
| 광차 | 광차 차고 | 60 | 1.16 | 적재 = 4 + 2Lv · 광차 수 = 1 + ⌊Lv/8⌋ · 왕복 = max(4, 10 − 0.2Lv)초 |
| 창고 | 창고 | 50 | 1.14 | 용량 = ⌊60 × 1.22^(Lv−1)⌋ · `pileCap` = 용량 ÷ 3 |
| 제련 | 제련소 | 400 | 1.3 | Lv1 해금 · 슬롯 = 1 + ⌊Lv/5⌋ · smeltSec = max(3, 12 − 0.3Lv) |
- 시작 숫자로 첫 1분: 광부 2 × 0.10 = 0.2개/초 × 평균 12금 ≈ 2.4금/초 → 곡괭이 Lv2(40금) 17초 · Lv3(46금) … 첫 5분에 업글 10번 남짓이 목표.
- 랜턴·펌프·포탑·두더지 집·진동계는 **원정 전용 도구**로 남음(지금 장비 탭). 엔진 업글과 섞지 않음.

## 5. 방치
- 떠난 시간 × 사슬을 그대로 빨리감기(창고 가득에서 멈춤). 상한 = `idleCapHours` 2시간 + 숙소 Lv × 0.25시간(최대 12).
- 돌아오면 카드 하나: "자리 비운 동안 광석 ○개 · 창고 ○/○" + 지금 시세 한 줄 + [바로 팔기] [나중에]. 글자 덩어리 3개 이하.

## 6. 화면 (부지 = 메인)
- HUD 한 줄: `💰 1,240  ⛏ 2.4/초  📦 38/60  🕒 1일 09:12`.
- 부지 위에 **보이는 것 = 엔진**: 갱도 입구 옆 pile 게이지(작은 광석 더미 그림이 커짐), 광차가 입구↔창고를 실제로 왕복(속도·대수 = 업글), 창고 위 게이지, 대장간 연기(제련 중일 때만), 광부들이 입구로 들어갔다 나옴.
- 건물 탭 → 기존 카드 한 장(그림 · 효과 한 줄 "캐기 0.10 → 0.13/초" · [올리기 💰46] · 길게 누르면 연속 구매). 마일스톤 Lv까지 남은 칸은 카드에 점 5개로.
- 갱도 입구 탭 → 갱도 목록(이름 · 남은 양 막대 · 광부 ± · 광종 아이콘). [새 원정] 버튼이 여기.
- 창고 탭 → 판매 카드(광종별 개수 · 지금 시세 · [다 팔기]).
