# 「용사님, 채굴하실게요~」 — HD-2D 비주얼 가이드 (v1 · 2026-10-24)

## 1. 한 줄 (2026-10-24 확정)
**기준 그림 = pxl 공식 예제 `no_magic_night`** (마녀 오두막 밤 장면: 벽난로·촛불·가마솥 발광·장판 위 빛 웅덩이·먼지). 형철이 "이 느낌"으로 확정.
→ **낮은 해상도의 두툼한 픽셀 + 여러 개의 따뜻한 광원 + 발광 헤일로 + 어두운 앰비언트.** 체크인의 아기자기함을 유지하면서 "빛"이 화면을 만든다.
- 기준 해상도: 장면 **256×224 → 화면에 4~5배 정수 확대**(체크인과 같은 급). "2배 해상도"보다 **빛이 주인공**이다.
- 레퍼런스 파일: `claude-pxl/examples/no_magic.px.js` (1,005줄 · `lamp()` 6개 + `lighting({ambient:0.42})` + `glow()` 3종). Code는 이 파일을 먼저 읽고 같은 문법으로 만든다.

## 2. 기술
- **아트 제작: `claude-pxl` 스킬**(`crsolver/claude-pxl` · MIT · Node 22+) — 타일·소품·광석·이펙트·**장면 조명**을 `.px.js` 코드로 만든다. 한 팔레트로 전부 뽑아 색이 튀지 않고, Code가 한 칸씩 고치며 반복 가능(루프 엔지니어링과 궁합).
  - 빌드 산출물: 스프라이트 PNG + 시트 JSON + 노멀맵(`bump()`) + GIF. 게임은 이 PNG를 쓴다.
- **런타임: PixiJS v8 (WebGL)** — 체크인 캔버스 2D 렌더러는 쓰지 않는다. 시스템 코드와 렌더는 분리.
- 조명 2단계: ① 정적 장면(지상 마을·사무소 내부)은 **pxl이 구운 조명**을 그대로 쓴다(런타임 비용 0). ② 갱도처럼 광원이 움직이는 곳만 **런타임 라이트**(`@pixi/lights` + pxl `bump()` 노멀맵). 폰 성능은 ②에서만 신경 쓴다.
- 필터: 틸트 시프트(상하 블러) · 색온도 LUT(층별) · 비네팅. 전부 **저사양 모드에서 꺼짐**.
- 입자: 먼지 · 파편 · 불꽃 · 반딧불(발광 이끼) — 풀링, 폰 상한 300개.

### 5-1. 초상 통일 규칙 (v0.3)
1. **GPT 요청 자체를 바꾼다**: 프롬프트에 pxl 장면(`office_night.png`)을 첨부하고 "48×48 캔버스, 최대 24색, 장면 팔레트 톤, 셀 셰이딩 2~3단계, 그라데이션 금지"를 명시. (「채굴하실게요 그림」 프로젝트에 모모로 1차 실험 중.)
2. **Code 후처리(`npm run portraits`) 강화**: 최근접 축소 → **pxl 팔레트(`art/shaft.px.js`+`office.px.js`의 pal 합집합)로 색 양자화** → 외곽선을 장면 잉크색 `#1a1220` 1px로 재추적 → 마젠타 제거. 디더링 금지. 64가 아니라 **48×48**로(장면 256폭에 64는 너무 큼).
3. **화면 배치**: 초상을 게임 장면 위에 바로 띄우지 않는다. 체크인처럼 **종이·나무 UI 틀(말풍선·편지·카드) 안에서만** 보여 주고, 틀 바깥 갱도 안에는 pxl 스프라이트만. 갱도 왼쪽 아래 "초상 카드"는 **제거**하고 광부 상태는 pxl 스프라이트 머리 위 작은 아이콘/말풍선으로.
4. 1~3을 해도 안 어울리면 초상도 pxl로 그린다(32×32, 모모 모자·안경 같은 실루엣 특징만 살림). 얼굴 동일성보다 **한 화면의 통일감**이 우선.

## 6-1. 화면 방향 (v0.3)
- **세로 기본, 반응형**(명세 §0). 장면 기준 해상도를 가로 256×224 하나로 못 박지 않는다 — 갱도 격자는 **칸 단위로 레이아웃**: 세로에선 칸 = 너비/12, 격자 16줄이 한 화면. 패드·PC는 칸 = min(너비/12, 높이/18) + 좌우 패널.
- 패럴랙스 겹은 세로에선 **위(하늘·지상)와 아래(깊은 어둠)**로, 가로에선 좌우로. 틸트 시프트는 세로에서 위아래 8%.
- pxl 장면(사무소·마을)은 256×224 그대로 두고, 세로 화면에선 너비에 맞춰 정수 확대 후 **위아래 여백에 UI**(상단 HUD, 하단 시트)를 둔다. 가로에선 양옆 여백에 UI.

## 7. Code 작업 지시 (비주얼 프로토타입)
1. `~/.claude/skills/pxl-pixel-art`에 `crsolver/claude-pxl` 클론. `examples/no_magic.px.js`를 끝까지 읽는다.
2. **초안이 이미 있다** — `art/shaft.px.js`(갱도 장면: 타일 13종 + 노멀맵 `bump("luma")` + 광차·랜턴·광부 + `lamp` 조명)와 `art/office/office.px.js`(사무소 내부 장면: 소품 25종 + 벽난로·램프·발광 광석 조명). 미리보기 `office_night.png` · `shaft_night.png` 동봉. 이걸 `art/`로 옮겨 **그대로 빌드**(`node bin/pxl.js build art/shaft.px.js`)하고 팔레트·문법을 이어받는다. 새로 짤 건 타일 변형 추가와 폰 성능용 정리 정도.
   - 주의: `bump()`는 `"bevel" | "dome" | "luma"` 문자열 + 옵션. anim 프레임은 `frame(grid(x, y, "..."))` 문법(`|` 구분 아님).
3. 산출 PNG를 PixiJS에 올리고, 랜턴 하나만 런타임 라이트로 움직이게(`@pixi/lights` + 타일 노멀맵). 곡괭이 주스(§3). 웹 링크 → 형철 폰 확인.
4. 캐릭터 도트(GPT 「채굴하실게요 그림」 프로젝트 산출): 돌망치 할아범 · 광부 3인 · 꼬마 두더지 · 모모 광산복 · 브로크 매입자 · 떠돌이 상인 — `art/raw/mine_*.png`. 후처리는 **§5-1 규칙**(48×48 + 팔레트 양자화 + 외곽선 재추적).
5. **v0.3 (2026-10-24 피드백 반영)**: ① 세로 모드 기본 + 반응형(§6-1) — 가로 강요·회전 안내 제거. ② 초상 카드를 갱도 화면에서 빼고 §5-1-3대로 UI 틀 안에서만. ③ `npm run portraits`에 팔레트 양자화 추가. ④ 세로 폰(390×844)·패드·PC 세 화면 스크린샷을 README에 첨부해서 링크 줄 것.

## 10. 캐릭터 품질 기준 상향 (2026-10-24 02:27 — 형철 레퍼런스 3장, `docs/ref/`)
§9의 광부 v2는 **아직 "단순"**. 새 기준:
- **그림 품질 = `docs/ref/char_quality.png`**: 2등신 치비, **32×40**, 재질마다 4~5단 명암, 머리카락 결·옷 주름·금속 반사까지 픽셀로. 외곽선은 잉크색이되 안쪽 선은 재질 어두운 색으로(검은 선 남발 금지). 광부는 1칸(32px) 폭·1.25칸 높이 → 격자 칸을 **36px**로 키워도 됨(세로 폰 12칸 = 432px, 16줄이면 스크롤 생김 → 세로에선 12줄 보이고 스크롤).
