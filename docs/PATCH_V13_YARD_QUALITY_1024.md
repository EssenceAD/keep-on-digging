## 2. 장면 재조립 (Claude, `yard.px.js` v3 — 384×224 유지, 좌표 `yard_lots.json` 그대로)
- **빈 터 = 공사 예정지**: 갈색 타원 삭제. 터 테두리에 말뚝+밧줄 울타리(앞면만 트임), 안에 다진 흙은 터의 60%만(모서리는 풀), 목재 더미·손수레·꽂힌 삽 중 2개, 앞에 빈 판자 표지판. **잠긴 터**(locked)는 천막+자재 상자, 울타리 사방.
- **건물 그림자**: 모든 터 밑에 `lot_shadow`(짙은 풀색 타원, 터보다 4px 큼, 아래로 3px 오프셋) — Code가 건물 밑에 alpha 0.35로 깔기. 빈 터일 땐 안 깔음.
- **바닥 변화**: 잔디 3톤(기본·짙은 패치·밝은 마모) — 길 양옆 6px은 마모 톤, 터 주변·나무 밑은 짙은 패치(타원 클러스터). 풀포기·들꽃은 뭉치로(1곳 3~5개), 흩뿌리기 금지.
- **밀도**: 위 줄 터 사이에 소나무 1그루씩이 터 모서리와 **겹치게**, 아래 줄 터 앞에 덤불·돌이 터 밑변을 가리게. 화면 좌우 끝 16px은 소나무·덤불 숲 띠.
- **낮 장면도 조명**: `yard_day`에 `lighting ambient 0.92, 따뜻한 색` + 모서리 비네트 + 건물·나무 밑 짙은 톤. `yard_dusk`(ambient 0.62 주황) 추가. 밤은 기존.
- **숲 채우기 타일** `forest_fill`(32×32, 어두운 소나무 캐노피 패턴) — 장면 바깥 채우기용.
- 캐릭터 대기 지점 `idleSpots`를 `yard_lots.json`에 추가(모닥불 옆 2, 우물 옆 1, 울타리 기대기 2, 광차 레일 옆 1, 다리 1).

## 3. Code (아트는 전부 푸시됨 — `art/yard/out/` 빌드 결과, `scripts/art.mjs`에 새 이름 복사 추가)
그리는 순서(위→아래): `yard_<time>` 장면 → 터마다 [빈 터: `lot_site_*`] 또는 [건물 그림자 → 건물 → 간판 판자] (기존처럼 바닥 y 정렬) → 장식·캐릭터·광차 → **`yard_front`**(앞 수풀, 건물 위에 겹침) → 글로우.
1. 장면 3종 `scenes/yard_day · yard_dusk · yard_night`: 06–16 낮, 16–20 해질녘, 20–06 밤(`isNight` 대신 3단). 장면에 **빈 터 자국이 없음** → 잠긴 터 덤불 코드·타원 코드 삭제. 모의 합성: `docs/ref/yard_v3_day.png`(낮) `yard_v3_dusk.png` `yard_v3_night.png` — 이 그림이 목표.
2. **터 9곳**(`yard_lots.json` id 0–8, 입구와 겹치던 옛 4번 삭제, id 다시 매김 — 저장된 `lot` 번호는 마이그레이션: 옛 5–9 → 4–8, 옛 4에 지은 건물은 빈 터로 옮김). 건물 바닥 `by = y + h/2 + 4` 그대로.
3. 빈 터(열림): `sprites/lot_site_a`(짝수 id) / `lot_site_b`(홀수) 를 **(lot.x-4, lot.y-20)** 에. 잠긴 터: `lot_site_locked`(짝수) / `lot_site_locked_b`(홀수) 같은 자리. 짓는 순간 사라지고 건물로.
4. 건물 그림자: 타원 **68×12, alpha 0.35, 중심 (cx, by-3)** (지금 56×10보다 크고 아래로).
5. **간판**: `sprites/sign_<key>` 판자(30×22)를 건물 **정면 (cx-15, by-38)** 에 겹치기 — 건물 그림의 글자 간판을 덮음. key: office→bag · lodge→bed · smelter→anvil · warehouse→crate · lanternshop→pick(랜턴 대신 곡괭이) · cartshed→cart · molehome→gem · pump→flask · turretshop→gear · (남는 mug는 술집 예비). 탭 → 카드(기존).
6. `sprites/yard_front`(384×224, 투명)를 **건물·캐릭터 위**에. 밤·해질녘 tint는 건물과 같은 값(`shade`)을 `lot_site_*`·간판·`yard_front`에도.
7. 화면 채우기: 장면 밖(PC 양옆, 세로 폰 위아래) 검정 대신 `sprites/forest_fill`(64×64, 이음새 없음) 반복 + 장면 가장자리 안쪽 8px 어둡게.
8. 캐릭터: 길에 일렬 금지. 라운드 밖엔 `yard_lots.json.idleSpots` 8곳에 흩어져 **멈춘 행동**(앉기·기대기·물 긷기 = idle 프레임) + 20~40초마다 다른 지점으로 걷기. 라운드 중엔 입구↔창고만 오감.
9. 회사 시트 건물 아이콘: 2줄 10칸 여백 과다 → 48px 아이콘 한 줄 5개 균등, `Lv·💰`만.
