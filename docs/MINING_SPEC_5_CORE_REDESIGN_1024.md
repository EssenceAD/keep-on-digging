# 5단계 명세: 핵심 루프 재설계 — 보물찾기 + 아이들러 (v1 · 2026-10-24 13:40)

> 형철 플레이 피드백(13:30): "광맥 캐는 시스템이 불친절·비직관. 보물찾기 느낌이 없고 손가락 드래그 노동. 자동이랑 차이 없음. 차라리 아이들러로 — 장비 업글·광부 늘리기·가공. 킵온마이닝은 특성 찍는 도파민이 있었는데 우린 애매." + 세계관 이름 미반영.
> 이 문서는 **명세2 §5(갱도 그리기)·§6(광부)를 대체**한다. 나머지(경매·판매·사건·결과)는 유지하되 아래 규칙과 충돌하면 이 문서 우선.

## 0. 새 한 줄
**"어디를 뚫을지 찾고(보물찾기) → 뚫으면 광부들이 알아서 캐고(아이들러) → 번 돈으로 장비·사람을 키워 더 깊이·더 빨리(성장)"** — 플레이어 손은 **탐사 · 꺾기 · 팔기 · 업글** 네 가지만.

## 1. 탐사 = 보물찾기 (텀오일 다우저·두더지·스캐너 구조)
탐사 단계를 15초짜리 통과 의례에서 **라운드의 핵심 재미 1**로. 지상 띠가 넓어지고(격자 위 3줄), 플레이어는 **도구 3종을 써서 "어디 밑에 뭐가 있나"를 추리**한다.

| 도구 | 하는 것 | 정보 | 업글(장비 탭) |
|---|---|---|---|
| 🐾 두더지 | 지상을 걸어 다니다 광맥 **열(x)** 위에서 킁킁 (자동, 15초) | "이 열 아래 뭔가 있다" — 깊이·종류 모름 | Lv↑: 걷는 속도·탐지 깊이 3→6→전부, Lv4: 광맥 크기 점 1~3개 |
| 📡 진동계 | 지상 칸을 **탭**하면 말뚝을 박고 3초 뒤 결과 (하루 n회) | "깊이 4~6에 중간 크기" — 종류 모름 | 횟수 2→5, 범위 ±2→±1, Lv3: 광종 색 |
| 🔦 투시 랜턴 | 탭한 지점 아래 **3×3**이 2초 보임 (하루 n회) | 종류·모양 정확 | 횟수 2→4, 범위 3×3→5×5 |
| 👀 지표 단서 | 생성 시 광맥 위 지상에 **단서 소품** 확률 배치: 변색 풀(구리) · 반짝이는 자갈(은·금) · 수정 조각(보석) · 푸른 이끼(발광) · 갈라진 땅(빈 공간) · 축축한 땅(지하수) | 공짜 힌트, 50%만 참 | 특성 「탐사」로 참 확률↑ |

- 탐사 결과는 **지상에 깃발/표시**로 남는다(두더지 킁킁한 열에 🐾, 진동계 결과 "4~6" 말뚝, 랜턴으로 본 칸은 반투명 기억). 시추 중에도 보임 → "저기 뚫자"가 **화면에 보이는 결정**이 된다.
- 탐사 끝 버튼 없음 — 도구를 다 쓰거나 [시추 시작]을 누르면 넘어감. 시추 중에도 남은 횟수로 탐사 가능.

## 2. 시추 = 텀오일식 "탭해서 세우고, 버튼으로 꺾기"
**갱도 경로 그리기·검증·"여기요!"·빨간 X 전부 삭제.**
- 지상 칸을 **탭** → 그 열에 **갱도 입구(드릴탑)** 가 세워지고 광부 둘이 **자동으로 수직으로** 판다. 뚫는 속도는 칸 종류(흙 0.45 · 바위 1.2 · 단단 ✕ 등급)대로.
- 갱도 머리 양옆에 항상 **[◀] [▶]** 버튼이 떠 있다(폰은 엄지 크기 56px). 누르면 그 방향으로 **1칸 꺾어서** 계속 판다. 다시 누르면 더 가고, [▼]로 다시 아래. 즉 플레이어 입력은 **방향 전환뿐**.
- 광맥에 닿으면 **자동으로 덩어리 전체 채굴**(지금과 같음) + 광차 자동. 다 캐면 광부는 머리로 돌아와 **멈추고 기다림** → "다음 어디?" 말풍선. 플레이어가 [◀][▶][▼] 누르면 재개.
- 동시 갱도 **최대 2개**(광차 차고 Lv3 → 3개). 각 갱도에 광부 조 1개(2명). 갱도가 많아지면 광부가 모자라 → 숙소 업글 동기.
- 사다리·레일은 자동. 중력: 광부는 자동 경로라 발밑을 파는 일이 없음 → **낙하는 사건(붕괴)에서만**. 붕괴 시 광부가 **자동으로 다시 뚫고 복구**(10초 손실), 토스트 1번만.
- 막힘(단단한 바위·고대석): 머리가 멈추고 "곡괭이 2등급이 필요해요 [장비]" 버튼이 바로 뜸 → 업글 유도. 돈 없으면 [◀][▶]로 돌아가면 됨.
- 지하수·가스는 그대로. 펌프는 자동 펌프 전까지 버튼 1개.

## 3. 아이들러 층 = 장비 · 사람 · 가공 (라운드 중에도 즉시)
회사 화면과 별개로 **하단 시트 [장비] 탭**이 라운드 중 항상 열린다. 텀오일처럼 **번 돈을 바로 쓰는 맛**. 가격은 `balance.js`, 라운드 순이익의 0.5~1.5배로 **자주** 찍게.

| 장비 | 단계 | 효과 |
|---|---|---|
| ⛏ 곡괭이 | 1→5 | 흙 속도 / 바위 뚫림(2) / 고대석(3) / 속도 ×1.5 / 광맥 2칸 동시 |
| 🚃 광차 | 1→5 | 적재 10→20, 속도 3→5, 대수 2→4 |
| 🏠 숙소 | 1→5 | 광부 3→7 (갱도 조 수 = 광부÷2) |
| 📦 창고 | 1→5 | 60→500 |
| 🐾 두더지 · 📡 진동계 · 🔦 랜턴 | 1→4 | §1 |
| 🔥 제련 | 0→3 | 광석→괴(×1.6) 라운드 중 자동, 동시 1→3 |
| 💧 펌프 · 🔫 포탑 | 0→3 | 자동 펌프 / 몬스터 자동 처리 |

- 회사 화면(부지 장면)은 이 장비들의 **건물 외형**이자 장식·어울림·방치 설정 자리. 업글 효과는 같은 표 하나(`balance.js upgrades`)로 — 장비 탭에서 올려도 부지 건물이 자라고, 부지에서 올려도 같음.
- 광부 영입(숙소 Lv업 시): 새 광부가 **다리에서 걸어 들어오는** 연출 + 이름·성격 카드. 이름은 §5.

## 4. 특성 트리 = 도파민 (킵온마이닝 방식으로 재조정)
- 포인트: **라운드마다 별 수만큼(1~3)** + 사무소 Lv. 1라운드에 최소 1점 → 매판 찍는다.
- 트리 3갈래 × **8단**, 효과는 전부 **숫자**로 보이게: 「채굴 +10%」「광차 +1」「흙 즉시 뚫림」「진동계 범위 ±1」「판매가 +5%」「급등 ×2.0」「대박 기준 12→10칸」… 찍는 순간 **갱도 위에 +10% 숫자가 튀고** 광부가 "오!" 말풍선.
- 8단째는 갈래마다 큰 것: 탐사 「광맥 전체 실루엣 보임」 / 채굴 「광부 조 +1」 / 장사 「시세 고정 2회」.

## 5. 세계관 · 이름 (형철 "붉은 수염·뚱보·금발이 뭐임")
광부는 체크인 세계의 인물로. 광부 카드·말풍선·결과 카드에 이름으로.

| 지금 | 이름 | 누구 | 성격(숫자는 명세4 §5) |
|---|---|---|---|
| 붉은 수염 | **브릭** | 브로크(대장장이)의 동생. 망치 대신 곡괭이를 잡음 | 성급 — 채굴 +10%, 사고 ×1.5 |
| 뚱보 | **툼바** | 체크인 여관 단골이던 드워프 먹보. 할아범이 밥값 대신 데려옴 | 느긋 — 운반 −10%, 가스 면역 |
| 금발 | **엘린** | 돌망치 할아범의 손녀. 랜턴 공방 집안 | 꼼꼼 — 유물 +20%, 손 랜턴 |
| 추가 광부 4명 | **도르, 핀, 마르타, 우글** | 숙소 Lv업마다 다리에서 걸어옴 | 랜덤 2종 |
- 2단계: 숙소 Lv5 광부는 **체크인 친구 닉네임**(랭킹·친구 목록)으로 영입 가능 — W.I.N.D 단톡 멤버 영웅화와 같은 재미.
- 할아범 이름 **「돌망치 그룬」**, 두더지 **「꼬물」**. 브로크·모모·버나드·떠돌이 상인은 체크인 그대로.
- 경매 길드 3곳은 체크인 길드 이름 그대로(이미).

## 6. 라운드 흐름 (바뀐 것만)
```
경매 → [탐사: 도구 써서 표시 남김] → [시추: 탭으로 입구, ◀▶▼로 꺾기, 자동 채굴] ⇄ [판매·장비 탭] → 철수/고갈 → 결과(별 → 특성 포인트) → 특성 찍기 → 회사(부지) → 경매
```
- 라운드 길이 목표 **4~6분**. 플레이어 입력 횟수 목표: 탐사 5~8탭, 시추 입구 2~3탭 + 꺾기 6~12탭, 판매 2~4탭, 업글 1~2탭.

## 7. 튜토리얼 수정 (ONBOARDING §2)
12단계를 새 조작에 맞게: 3 "두더지가 킁킁한 열을 **탭**해서 입구를 세워요" → 4 "광부들이 알아서 파요. 바위를 만나면 느려져요" → 5 "**[▶]**를 눌러 구리 쪽으로 꺾어요" → 6 자동 채굴·광차 → 7~8 판매 → 9 "진동계로 땅을 **탭**해 보세요: 깊이 6~7!" → 10 "입구를 하나 더 세워요" → 11 상인에게 금 → 12 "[장비]에서 곡괭이를 올려 보세요" → 13 철수 → 결과 → **특성 1점 찍기** → 첫 경매.

## 8. 삭제·정리
- 삭제: 경로 그리기·미리보기·검증·"여기요!"·빨간 경고선·스크롤/그리기 구분 규칙(v0.8 §1 — 이제 드래그는 항상 화면 끌기)·발밑 파기 경고.
- 유지: 중력(붕괴용)·사건 4종·대박·시세·매입자·결과 카드·방치·회사·계정.
- `balance.js`에 `upgrades`(장비표)·`talents`(3×8)·`tools`(탐사 도구) 표 통합. 회사 건물 효과는 `upgrades`를 참조.

## 9. Code 순서 (단계마다 배포)
1. 시추 교체: 입구 탭 + 자동 수직 + ◀▶▼ 꺾기 + 자동 채굴·복귀·대기 말풍선. 그리기 코드 삭제.
2. 탐사 도구 3종 + 지표 단서 + 지상 표시 잔존.
3. 장비 탭(라운드 중) + `upgrades` 표 통합(회사 건물과 한 표).
4. 특성 3×8 + 라운드 별 포인트 + 찍을 때 연출.
5. 이름·세계관 교체(브릭·툼바·엘린·그룬·꼬물) + 추가 광부 영입 연출.
6. 튜토리얼 재작성 + 설명서.
7. v1.0 부지 장면(PATCH_V10)·v0.9-b와 합쳐 배포. 형철 폰 테스트.
