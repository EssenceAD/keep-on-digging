# v0.8 패치 — 형철 PC 플레이 피드백 (2026-10-24 12:04)

> ① PC에서 갱도가 화면 아래로 내려가는데 드래그가 전부 "갱도 그리기"로 잡혀 스크롤을 못 함 ② 광차 1대라 진행이 답답함 ③ 경매가 텀오일처럼 "어디가 이득인지"가 한눈에 안 보임.

## 1. 스크롤 vs 그리기 (PC·패드·폰 공통)
- **PC·가로 패드**: 칸 = `min(높이/17, 너비/12)`로 **격자 16줄이 한 화면에 다 들어가게**(스크롤 자체를 없앰). 좌우 패널은 남는 폭. 마우스 휠은 혹시 넘칠 때만 스크롤.
- **세로 폰**: 격자 12줄 보이고 나머지 스크롤. 규칙:
  - 드래그 시작 칸이 **그릴 수 있는 칸**(지상 줄 · 뚫린 칸 · 뚫린 칸의 인접 칸)이면 → 갱도 그리기.
  - 그 외 칸(깊은 흙·바위·광맥)에서 시작하면 → **화면 끌기**.
  - 두 손가락은 항상 화면 끌기.
  - 격자 오른쪽에 **얇은 스크롤 막대 + 위/아래 화살표**(탭하면 6줄씩).
- 그리기 시작 가능한 칸은 손을 대는 순간 **테두리가 살짝 밝아져서** "여기서 그릴 수 있다"를 알려 줌.

## 2. 진행 속도 (답답함)
`balance.js`:
- 광차 **기본 2대**(차고 Lv3 → 3대, Lv5 → 4대). 속도 2 → **3칸/초**, 적재 8 → **10**.
- 광부 3명 역할: **선두 2명이 동시에 캐고** 1명 운반(지금 1명 캐고 2명 운반). 광맥 덩어리는 양쪽에서 캐 들어감.
- 흙 0.6 → **0.45초**, 바위 1.5 → **1.2초**, 광맥 1.0 → **0.8초**.
- 광차가 갱도 **끝까지 레일 타고 들어와** 바로 받음(운반 광부는 광차 없을 때만 지상까지).
- 라운드 목표 길이 5~8분은 유지 — 구획 광맥 총량을 +30% 늘려서 상쇄.

## 3. 경매 — 한눈에 "이득인가" (텀오일 방식으로 단순화)
### 3-1. 카드에 **예상 가치** 표시
- 카드마다 `예상 가치 420~690금` (크기·힌트로 계산: 기본 광맥 기대치 × 힌트 보정, ±25% 범위). 특성 「탐사 4」면 범위가 좁아짐(±10%).
- 현재가 아래 **이익 막대**: `예상 가치(중간값) − 현재가` → 초록(여유) · 노랑(아슬) · 빨강(손해). 호가가 올라갈수록 막대가 줄어들어 **"여기서 멈춰야겠다"가 보임**.

### 3-2. 입찰 방식 교체 (2라운드·3버튼 → 연타 1버튼)
- 버튼 **[올리기 +10%]** 하나 + [포기]. 누를 때마다 현재가 +10%, 길드 3곳이 **즉시**(0.4초 안에) 따라오거나(말풍선 "{g}!") 포기(고개 젓고 회색).
- 길드는 각자 **한도**(평가액 × 성향 계수)까지만 따라옴. 한도 넘으면 포기.
- 플레이어가 올린 뒤 **2초 동안 아무도 안 올리면 낙찰**(망치 카운트 "3·2·1" 표시). 길드가 올렸으면 다시 플레이어 차례.
- 길드가 최고가인 채 플레이어가 [포기]하거나 금화 부족 → 그 길드 낙찰(길드 환호). 세 구획 다 놓치면 공짜 구획.
- 화면 구성: 카드 가운데 크게 1장(선택한 구획) · 위에 길드 3명 초상 + 각자 **현재 호가 숫자가 머리 위**에 · 아래 [올리기] [포기] · 내 금화 항상 표시.
- 세 구획 중 하나만 입찰 가능(지금과 같음). 입찰 안 한 두 장은 길드끼리 가져가는 연출 1초.

### 3-3. 길드 성향을 **보이게**
- 초상 옆 작은 라벨: 심연낚시 「공격적」 · 탑오르는중 「신중」 · 방패장인 「변덕」. 설명서에 "공격적 길드는 예상 가치 1.3배까지 따라와요".

## 4. 그 밖에
- 결과 카드 위 12단계 할아범 말풍선 → 카드 **아래**로(Code 질문 답).
- 튜토리얼 8단계(판매) 뒤에 **"광차가 2대라 쉬지 않고 올라와요"** 한 줄(2대 기본이 됐으니).
