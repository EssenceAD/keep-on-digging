# 명세 6 — 구조 총점검 · 재설계 (형철 플레이 평가 10/24 20:50: "5점 만점에 1점")

> 평가 원문: 경매는 한도까지 올려도 길드가 무조건 따라붙어 낙찰 불가 → 공짜 광산 반복 · 특성은 금방 다 찍힘 · 건물 업글은 옷 갈아입히기 · 마을 화면이 왜 있나 · 아이들러 느낌 전혀 없음 · 텀오일·킵온마이닝 게임성을 못 따라감.
> 요청: 컨텐츠 때려박기 말고 **구조 설계 총점검 → 중독성 있는 새 방향**.

## 0. 한 줄 진단
**돈이 자라는 엔진이 없다.** 라운드 수입 = 낙찰 땅의 광맥 가치(고정)이고, 업글·건물·특성은 그 고정값을 조금 빨리 캐게 해줄 뿐이라 수입이 커지지 않는다. 그래서 (1) 업글 살 이유가 없고 (2) 방치해도 늘어나는 게 없고 (3) 경매에서 지면 공짜 S 땅으로 떨어져 "성장"이 끊긴다. 텀오일·아이들러의 공통 척추 = **업글 → 수입 ↑ → 더 큰 투자 → 수입 ↑↑ (지수 곡선)** 가 통째로 빠져 있다.

## 2. 레퍼런스가 실제로 돌아가는 법 (조사)
**텀오일** — 1년(10~15분) 루프: 마을에서 업글 쇼핑(말·파이프·두더지·스캐너·사일로·은행 대출·바에서 뇌물) → 땅 경매(라이벌이 되사가며 경쟁하지만 **땅은 늘 생김**) → 1년 채굴(좌·우 상회 시세 보며 저장했다 파는 손맛) → 결산 그래프 → **마을 지분 경매, 50%면 시장 = 지역 클리어, 다음 지역**. 핵심은 "업글이 끝까지 계속 나온다"와 "라이벌도 같이 성장한다"는 것. 리뷰어들이 중독을 말하는 지점은 경매가 아니라 **시세 타이밍 + 다음 해 업글 계획**. ([gamepitt](https://www.gamepitt.co.uk/?p=6110), [pocketgamer](https://www.pocketgamer.com/turmoil/review/))
**킵온마이닝** — 수동 채굴 → 몇 분 안에 제작·자동화 → 레벨업마다 **탈렌트 카드 선택(강한 효과 + 바위 체력 증가 트레이드오프)** → 백그라운드 생산. 평가 갈림: 페이싱·돌아왔을 때 보상은 호평, 방치 광산이 능동 플레이보다 "몇 자릿수" 약해 쓸모없다는 혹평. 교훈: **방치 수입이 능동의 보조가 아니라 본체여야** 아이들러다. ([gaminghq](https://gaminghq.eu/2025/11/22/keep-on-mining-review/), [incrementaldb](https://www.incrementaldb.com/community/review/5998))
**아이들러 수학 (Pecorella)** — `다음 비용 = 기본 × r^보유수`(r≈1.07~1.15), 생산은 보유수에 선형 → 사고·막힘·사고의 "파도". 막히면 **프레스티지**(리셋 + 영구 배수)로 곡선 전체를 들어올림. 재미 = 지금 뭘 사는 게 최선인지 바뀌는 "선택" + 다음 구매까지의 "기대". ([gamedeveloper](https://www.gamedeveloper.com/design/the-math-of-idle-games-part-i))
**Idle Miner Tycoon** — 갱도(캐기) → 승강기(운반) → 창고(현금화) **3단 병목**: 어느 하나 올리면 숫자가 바로 보이고, 다음 병목이 다른 데로 옮겨가서 계속 살 게 생김. 프레스티지(광산 리셋+배수) · 대륙(새 광산 세트) · 매니저(자동화). ([kolibri](https://www.kolibrigames.com/blog/economy-in-free-to-play-mobile-games-part-2/))

## 3. 새 척추 — "광산은 항상 돌아간다"
> 회사는 **갱도를 소유**하고, 갱도는 **초당 광석을 생산**한다(엔진). 능동 플레이(원정)는 **새 갱도를 얻는 행위**라서 한 번 할 때마다 엔진이 영구히 커진다. 경매는 "지면 끝"이 아니라 "얼마에 사느냐"다. 지역이 고갈되면 이사(회차)하며 배수가 붙는다.

### 3-1. 엔진 (아이들러 본체) — 부지 화면이 **메인 화면**
- 소유 갱도마다: `생산/초 = 배치 광부 × 곡괭이 등급 × 깊이 계수`. 광석은 **광차**(운반 병목: 대수·적재·속도)로 **창고**(현금화 병목: 용량, 가득 차면 생산 멈춤)로. 세 병목이 번갈아 걸리게 숫자 설계.
- 업글은 **Lv 20+ 무한형**, 비용 `기본 × 1.15^Lv`(곡괭이·광차·숙소·창고·제련), 효과는 선형 + 10·25·50Lv에서 ×2 (파도). 지금 5단 표는 폐기.
- 창고 → 판매는 **수동이 기본**(시세 보고 팔기 = 세션의 결정), 십장(매니저) 고용 시 자동 판매(가격 조건 설정). 시세·급등·두 상회는 유지.
- 방치: 떠난 시간 × 생산(창고 상한). 돌아오면 "창고 가득 💰" 카드 하나 + 지금 시세 → **팔까, 기다릴까**가 첫 결정.
- 부지 화면에서 **보이는 것 = 엔진**: 갱도 입구마다 광부 수·깊이 바, 광차 굴러감, 창고 게이지, 제련 연기. 숫자가 올라가는 걸 보는 화면이라 존재 이유가 생김. 회사 화면 별도 전환 삭제.

### 3-2. 원정 (텀오일 손맛) — 능동 플레이
- 지도에서 **후보 땅 3곳**(매일 갱신). 가격 = 크기 × 지역 계수(힌트 구매는 선택). 길드는 **내가 고르는 데 늦으면** 되사가는 압박이지 벽이 아님: 길드 한도 = 예상가치 × 0.5~0.7, 플레이어는 **항상 한 곳은 살 수 있게**(최저가 땅엔 길드 미참가). 공짜 땅 삭제.
- 원정 = 지금의 시추 플레이 3~6분 그대로(진동계·랜턴·두더지·중력·사건·유물). **끝나면 그 땅이 내 갱도가 됨**(엔진에 추가, 발견한 광맥 칸 수 = 갱도 매장량). 즉 라운드 보상 = 돈이 아니라 **영구 생산 시설**.
- 갱도 매장량은 날짜가 가며 줄고(고갈 바), 고갈되면 폐쇄 → 새 원정 동기. 숙소 Lv = 동시 운영 갱도 수 상한.

### 3-3. 회차 (프레스티지) · 지역 · 끝
- **지역**: 뒷산 → 폐광 → 설산 → …(타일·광종 믹스·사건 다름). 지역마다 **광산 조합 지분** 경매가 N일마다 열리고(길드 3곳과 경쟁, 길드도 같이 성장), **50% = 조합장 → 지역 클리어**(2~3시간 분량).
- 클리어 시 다음 지역으로 **이사**: 갱도·건물 Lv 리셋, **회사 평판 +1** → 모든 생산 +25%/평판, 시작 자금 증가, 특성 포인트 = 평판으로만 지급(희소 복구). 특성 트리는 지역마다 다시 찍음(빌드 바꾸는 재미).

### 3-4. 해금 템포 (첫 60분에 5분마다 새 것)
0' 광부 1명 수동 채굴(탭) → 3' 광부 자동 채굴 → 5' 광차 → 8' 창고·판매·시세 → 12' 첫 원정(지도) → 18' 두 번째 갱도 → 22' 제련 → 28' 두더지·진동계 업글 → 35' 길드 등장·되사기 → 40' 십장(자동 판매) → 50' 유물·폐광 → 60' 지분 경매 안내. 표는 Code가 `unlocks.js`로.

### 3-5. 세션 설계 (5분짜리)
돌아옴 → 창고 가득 카드 → 시세 보고 판매 → 업글 1~2개(병목 옮기기) → (선택) 원정 1회 4분 → 창고 비운 채로 나감. 한 화면 글자 덩어리 ≤3 규칙 유지.

## 4. 유지 / 폐기
- **유지**: 아트·pxl 파이프라인 전부, 시추 조작·도구·중력·사건, 시세·급등·두 상회, 길드 캐릭터·대사, 제보·공지, 모모·할아범.
- **폐기**: 공짜 땅, 라운드별 특성 포인트, 5단 업글 표, 별도 회사 화면, 경매 "무조건 따라붙기", 어울림(장식 보너스는 평판 상점으로 흡수).

## 5. 단계 (각 단계 배포 → 형철 플레이 → 다음)
1. **엔진**: 소유 갱도 모델 + 생산/광차/창고 병목 + 무한 업글 곡선 + 방치 + 부지 = 메인 화면. (기존 시추는 "원정"으로 이름만)
2. **원정→갱도 전환** + 지도 3후보 + 길드 되사기 + 고갈.
3. **해금 템포 표** + 십장 + 특성 재배치.
4. **지역·지분·이사(회차)**.
숫자는 전부 `balance.js`에 새 섹션(`engine`, `expedition`, `prestige`, `unlocks`)으로 — 형철이 만진다.
